# 경쟁사 후킹 패턴 라이브러리 (2026-08 분석)

> 잘 되는 사주·운세 계정들의 공통 패턴을 추출해 오롭미 톤으로 재창작하기 위한 공식 모음.
> 복사가 아니라 패턴 적용 — 문장은 전부 오롭미 오리지널로.

## 관찰 대상 (리서치 기반)

- 일간별 성격 시리즈 강자: 살구사주(@salgusaju) 류 — "○○일간인 사람 특징" 카드뉴스 반복 포맷
- 페이백언니(@payback_unnie) 류 — 구어체 반말 후킹 + "이거 완전 나잖아" 댓글 유도
- 포스텔러 — 귀여운 캐릭터 프론트 + 가벼운 진입(테스트) → 유료 전환
- 청월당 류 — 인물(선생님) 신뢰 프론트 + 진중한 해석 (얼굴 노출 불가라 오롭이로 대체)

## 검증된 후킹 공식 7가지

1. **명명 후킹**: "갑목인 사람" "임수 여자" — 자기 라벨을 제목에 박기.
   댓글에 "나 갑목인데 소름" 유도. → 우리: 일간 시리즈, 오행 캐릭터.
2. **부정 후킹**: "○○일간이 제일 힘들어하는 것" — 공감 페인포인트 먼저.
   → 우리: 각 일간의 '그늘' 파트가 소재.
3. **관계 태그 유도**: "주변에 무토 있으면 보여주세요" — 태그가 곧 도달.
   → 우리: "너 이거잖아 하면서 친구 태그해주세요".
4. **겉/속 반전**: "겉은 차분한데 속은 ○○" — 바넘 효과의 핵심 구조.
   → 우리: 카드 2번 슬라이드 '겉과 속' 고정.
5. **시리즈 예고**: "다음 편은 을목" — 팔로우 이유 만들기.
   → 우리: 10부작 순서 고정 (갑→을→병→정→무→기→경→신→임→계).
6. **행동 유도 마무리**: 마지막 슬라이드는 항상 CTA — 우리는 "내 일간 모르면 30초 무료 확인".
7. **발행 리듬**: 잘 되는 계정은 요일 고정 반복 (주 2~3회, 같은 포맷). 포맷 피로보다 포맷 인지가 먼저 온다.

## 오롭미 차별화 포인트 (콘텐츠에 반복 노출할 것)

- "계산은 만세력, 해석은 AI" — AI 사주의 고질병(팔자 계산 오류)이 구조적으로 없음
- 회원가입 없음, 30초
- 실판매 기준 정직한 가격 카운터 (마케팅 소재로도 씀: "가짜 품절 대신 진짜 숫자")
- 오롭이 캐릭터 = 계정의 얼굴 (사람 얼굴 없이 기억점 확보)

## 톤 가이드
