# 8월 당근 100만원 플랜 (2026-08-05 작성)

## 목표 역산

| 항목 | 수치 |
|---|---|
| 목표 | 8월 매출 100만원 (당근 채널 중심) |
| 남은 기간 | 8/5~8/31, 27일 |
| 평균 객단가 가정 | 9,500원 (평생사주 6,900 + 번들 17,900 믹스) |

| 필요 문의(전환 30% 가정) | 하루 13건 채팅 |

**솔직한 평가**: 무명 프로필 첫 달에 하루 4건은 공격적입니다. 당근 사주 업체들은 보통 후기 12개를 1년에 쌓아요. 다만 그들은 대면 상담(1인 25,000원, 회전 느림)이고 우리는 **비대면 즉시 발급 + 1/3 가격**이라 회전율 구조가 다릅니다. 승부처는 "후기 속도"예요.

**현실적 단계 목표**:
- 1주차(8/5~11): 체험단 10명 소화 → **후기 5개 확보**(사이트 후기 섹션 자동 점등) · 유료 5건
- 2주차(8/12~18): 후기 10개 · 유료 20건 (약 19만원)
- 3주차(8/19~25): 후기 20개 · 유료 35건 (약 33만원)
- 4주차(8/26~31): 유료 45건 (약 43만원)
- **누적 약 100만원** — 2주차에 미달이면 가격이 아니라 노출(소식 빈도·판매글 개수)을 먼저 늘린다.

## 왜 후기가 먼저인가

후기 0개면 아무리 좋은 상품도 안 팔립니다. 반대로 후기 10개가 쌓이면 같은 글에 같은 가격이어도 문의가 붙어요. 그래서 **1주차는 매출을 포기하고 후기에 올인**합니다.

- 체험단 10명 = 원가 약 3,000원(리포트당 ~300원). 후기 10개를 3천원에 사는 셈.
- 사이트 후기 섹션은 5건부터 자동 점등되게 해뒀어요(그 전엔 "후기 1명"이 역효과라 숨김).
- 당근 후기와 사이트 후기는 별개 — 당근은 "단골 맺기+후기" 유도, 사이트는 리포트 하단 폼.
