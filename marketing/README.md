## 카드뉴스 PNG 만들기 (자동)

dev 서버 켠 상태에서:

```bash
npx tsx scripts/export-cards.ts
```

→ `marketing/cards/{일간}/slide-0.png ~ slide-5.png` 60장 자동 생성.
오행 테스트 스토리 카드(9:16)는 각 결과 페이지의 "스토리용 이미지 저장" 버튼으로 받거나
`/test/ohaeng/{type}/story-image`에서 저장.
