# 당근 비즈프로필 — 복붙용 완성문

근거: [docs/danggeun-pattern-formula.md](../docs/danggeun-pattern-formula.md) (상위 10곳 실측)

**작성 원칙 3개 — 어기면 안 됨**
1. 후기·단골·누적 인원 숫자를 **한 글자도 쓰지 않는다.** 실제 0건이다.
2. 존재한 적 없는 **정가·취소선을 만들지 않는다.** 표시광고법상 허위 할인.
3. **"직접 해석" "AI 아님"류 문구 금지.** 해석문 집필은 AI다. 대신 "계산에는 안 쓴다"는 사실이라 얼마든지 써도 된다.

## ③ 가격표

> 규격: 3단 · **모든 가격에 "원~"** · 900원 끝자리 통일 · A는 무배지, B·C에만 대표 배지 · 설명문에 숫자 1개 이상 · 인원수 명시

| 항목명 | 가격 | 대표 |
|---|---|:---:|
| `간편 사주 (1인)` | `4,900원~` | |
| `종합 사주풀이 (1인)` | `14,900원~` | ★ |
| `2인 궁합 + 각자 종합 (2인)` | `24,900원~` | ★ |

**설명문 (각 항목에 그대로 붙여넣기)**

A —
```
만세력 1900~2050 기준으로 팔자 여덟 글자를 계산해 타고난 기질과 오행 균형을 정리해 드립니다. PDF 10페이지, 신청 후 1~2분 내 발송.
```

B —
```
PDF 26페이지, 약 22,000자. 기질과 성격, 재물과 직업, 연애와 인간관계, 그리고 10년 단위 대운 시간표까지 전부 담습니다. 신청 후 15분 내 발송. 단골 등록하시면 11,900원.
```

C —
```
두 분 각각의 종합 사주 26페이지와 궁합을 한 번에 묶어 드립니다. 종합 사주를 따로 두 번 신청하시는 것(29,800원)보다 4,900원 저렴합니다. 신청 후 15분 내 발송.
```

**운영 메모 (붙여넣지 말 것)**
- A 발급 = 관리자 콘솔에서 `평생사주 종합` / B = `정통 심층사주` / C = `정통 심층사주` 2건 + `연애·궁합` 1건
- 정가 취소선은 넣지 않는다. **실재하는 할인은 단골가 11,900원 하나뿐**이고 그것만 표기 가능

## ⑩ 후기 0건 구간 운용 규칙 (내부)

1. **5점 후기에 답글을 달지 않는다.** 상위 10곳 중 7곳이 후기탭 답글 0건, 5점 감사 답글은 100건 중 0건
2. 답글은 **저평점 진화**와 **사실 정정**에만. 반박하지 않는다 — 반박은 악평의 체류시간을 늘린다
3. 감사 인사는 **소식 게시글 댓글**에서만. 단 초 단위로 몰아 달지 않는다(9초 간격 9연속은 조작으로 읽힘)
4. **"15분"이 우리의 유일한 숫자 무기다.** 상위권 최속이 12시간이고 그게 후기에 "놀랐어요"로 인용된다. 고객이 이 숫자를 후기에 직접 적게 만드는 것이 첫 100건의 목표
5. 첫 후기 10건까지는 질문 응답을 최우선 처리. **후기 길이는 왕복 횟수에 비례**한다
