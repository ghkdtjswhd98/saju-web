| 발견 | 수치 | 우리 대응 |
|---|---|---|
| 카드뉴스가 릴스보다 인게이지먼트가 높고 저장률이 22% 높다 | 캐러셀 0.55% vs 릴스 0.50% vs 단일이미지 0.45%, 6~10장이 최적 | 카드뉴스 = 저장·전환 / 릴스 = 신규 유입, 역할 분리 |

| 본문 외부 링크는 도달을 깎는다 | 10개 글 중 1~2개만 권장 | 링크는 **첫 답글**에만 |

| 발행은 완벽함보다 일관성 | 주 1회 완벽 < 주 3회 꾸준 | 슬롯 고정제 |

## 1. 인스타그램

### 프로필 3줄 공식
```
사주, 계산부터 정확하게 🌙
만세력으로 팔자 계산 · 해석은 깊이 있게 | 회원가입 없이 30초
↓ 무료로 내 사주 확인하기
```
- 링크: 1개만 (`https://saju-web-orobmi.vercel.app`)
- 하이라이트 3종: **①리포트 미리보기**(샘플 페이지 캡처) **②후기** **③오롭이의 오늘**

### 콘텐츠 3종과 제작 시간

| 포맷 | 소요 | 목적 | 소재 |
|---|---|---|---|
| 일간 카드뉴스 (6~8장) | 5분 | 저장·전환 | `marketing/cards/{일간}/slide-0~5.png` 그대로 |
| 릴스 (15~25초) | 15분 | 신규 유입 | 카드뉴스를 빠르게 넘기며 화면 녹화 + 자막 |
| 상품 카드 (1장) | 2분 | 전환 | `marketing/sale/{상품}.png` |

### 발행 슬롯 (고정)
- **화·목·토 오전 10~12시** — 카드뉴스
- **화·금 오전 9~11시** — 릴스
- 주 5회. 완벽한 1회보다 꾸준한 5회.

### 첫 3초 후킹 6유형 (릴스 오프닝)
1. **부정형** — "이 일간이면 지금 이직하면 후회합니다"
2. **비교형** — "잘 맞는 사주 vs 안 맞는 사주, 차이는 하나"
3. **호기심형** — "사주에서 '나'는 여덟 글자 중 딱 한 글자예요"
4. **스토리형** — "AI한테 사주 물어봤다가 팔자가 매번 바뀌는 이유"
5. **자기라벨형** — "무토인 사람 특징 (댓글에 소름 주의)"
6. **밈형** — 오롭이가 놀라는 컷 하나로 시작

### 릴스 대본 5개 (얼굴 없이 촬영 가능)

**대본 1 — "AI 사주의 함정" (20초)**
```
[0-3초] 화면: 챗봇에 생년월일 입력하는 손 / 자막: "AI한테 사주 물어봤어요"
[3-8초] 같은 질문 두 번, 다른 팔자가 나오는 화면 / 자막: "근데 물어볼 때마다 팔자가 달라요"
[8-14초] 만세력 앱과 대조하는 화면 / 자막: "AI는 계산을 못 해요. 지식으로 '추측'하거든요"
[14-20초] 오롭미 결과 화면 / 자막: "그래서 계산은 만세력, 해석만 AI. 프로필 링크에서 무료로"
```

**대본 2 — "일간 시리즈" (18초)**
```
[0-3초] 오롭이 등장 컷 / 자막: "무토인 사람, 이거 다 맞을걸요"
[3-15초] 카드뉴스 4장 빠르게 넘김 / 각 장 자막 그대로
[15-18초] / 자막: "내 일간 모르면? 프로필 링크 30초 무료"
```

**대본 3 — "오행 테스트 유도" (15초)**
```
[0-3초] 자막: "스트레스 풀리는 법으로 보는 내 기운"
[3-12초] 5개 선택지를 하나씩 / "몸 움직여야=목 / 사람 만나야=화 / 먹어야=토 / 정리해야=금 / 혼자 있어야=수"
[12-15초] / 자막: "댓글에 남겨주세요. 12문항 테스트는 프로필에"
```

**대본 4 — "대운 소개" (22초)**
```
[0-4초] 자막: "사주에서 제일 중요한 건 '언제'예요"
[4-12초] 대운 시간표 화면 스크롤 / 자막: "8세, 18세, 28세... 10년마다 판이 바뀌어요"
[12-18초] / 자막: "지금 몇 세인지에 따라 같은 사주도 완전히 다르게 읽혀요"
[18-22초] / 자막: "내 전환점이 몇 살인지, 프로필 링크에서"
```

**대본 5 — "후기 리액션" (15초)**
```
[0-3초] 후기 스크린샷 / 자막: "이런 후기를 받았어요"
[3-10초] 후기 텍스트 확대 (실제 후기만, 각색 금지)
[10-15초] / 자막: "좋은 말만 하지 않아요. 그늘도 짚어드려요"
```
※ 후기 5건 모이기 전까지는 대본 5 보류 (실후기 없이는 제작 금지)

### 후킹 문구 20개 (캡션 첫 줄)
1. 무토인 사람, 이거 다 맞을걸요
2. AI 사주는 왜 물어볼 때마다 팔자가 바뀔까
3. 사주에서 '나'는 여덟 글자 중 딱 한 글자예요
4. 겉으론 멀쩡한데 속으로 무너지는 일간
5. 돈이 새는 사주에는 공통점이 있어요
6. 이 사주는 이직하면 안 됩니다 (지금은)
7. 친구랑 결과 비교해보세요, 다르면 진짜예요
8. 태어난 시간 몰라도 사주 봅니다
9. 사주 잘 맞는다는 말, 사실 이 뜻이에요
10. 10년마다 판이 바뀌는 거 알고 계셨어요?
11. 무료인데 이 정도까지 나와도 되나요
12. 좋은 말만 하는 사주는 의심하세요
13. 올해 유독 힘들었다면 이 흐름일 수 있어요
14. 연애가 반복해서 같은 지점에서 깨진다면
15. 내 일간이 뭔지 모르면 사주 본 게 아니에요
16. 이 조합이면 사람들이 자꾸 기대러 와요
17. 사주 보러 다니지 마세요, 한 번에 끝내세요
18. 30초면 나오는데 왜 안 보세요
19. 팔자 계산, 다른 앱이랑 대조해보셔도 돼요
20. 내년에 뭐가 달라지는지 미리 보는 법

## 2. 스레드

### 글 구조 공식
```
[1줄] 숫자 · 의외성 · 질문 중 하나 (여기서 스크롤이 멈춰야 함)
[2~7줄] 본문 — 8줄 이내, 반말/구어체, 오롭이 1인칭도 OK
[마지막] 질문으로 끝내기 (댓글 = 좋아요 8개)
```
- 링크는 **본문 금지**, 첫 답글에만. 링크 포함 글은 전체의 10~15%(주 1회)
- 발행 직후 10분간 답글 달아주기 (초기 반응 속도가 도달을 만듦)

### 카테고리 4개 고정 (토픽 오서리티)
① 오늘의 운세 · ② 일간 성격 · ③ 사주 상식 · ④ Q&A 답글

### 발행 리듬
주 5회 이상(하루 1회). 몰아 올리고 사라지는 게 최악.

### 예시 글 10개

**1 (숫자 훅)**
```
사주 여덟 글자 중에 '나'는 딱 한 글자예요.
태어난 날의 하늘 글자, 일간.
나머지 일곱은 내가 살아가는 무대고요.

무대 탓만 하다가 정작 자기 자신을 모르는 경우가 많아요.
당신 일간은 뭐예요?
```

**2 (의외성 훅)**
```
AI한테 사주 물어보면 팔자가 매번 달라지는 거 아셨어요?

계산을 '아는 지식'으로 추측하거든요.
만세력은 절기랑 음력 윤달까지 봐야 해서 추측으론 안 맞아요.

팔자가 틀리면 그 뒤 해석은 전부 남 얘기예요.
한번 대조해보세요, 진짜 소름 돋습니다.
```

**3 (질문 훅 · 댓글 유도)**
```
스트레스 풀리는 법으로 기운 맞히기 해볼게요.

몸 움직여야 풀림 → 나무
사람 만나야 풀림 → 불
먹어야 풀림 → 흙
정리해야 풀림 → 쇠
혼자 있어야 풀림 → 물

댓글에 남겨주시면 한 줄씩 풀어드릴게요.
```

**4 (역설 훅)**
```
좋은 말만 해주는 사주는 좀 의심해보세요.

사주에는 원래 강점이랑 그늘이 같이 있어요.
그늘을 안 짚어주면 그건 위로지 분석이 아니에요.

듣기 좋은 말은 그때뿐이고, 정확한 말은 인생에 남아요.
```

**5 (시간축 훅)**
```
사주에서 제일 중요한 건 '언제'예요.

10년마다 판이 통째로 바뀌거든요.
같은 사주라도 28세랑 38세는 완전히 다르게 읽혀요.

지금이 뿌리 내리는 10년인지, 펼치는 10년인지.
그거 모르고 결정하면 타이밍을 놓쳐요.
```

**6 (공감 훅)**
```
연애가 자꾸 같은 지점에서 깨진다면
상대가 문제가 아니라 패턴일 수 있어요.

힘들 때 말 안 하고 혼자 삼키는 사람,
상대는 그 침묵을 거절로 읽어요.

이건 성격이 아니라 구조라서 알면 바꿀 수 있어요.
```

**7 (반박 훅)**
```
"사주 미신 아니에요?" 소리 많이 들어요.

저희 답은 이래요.
수천 년 쌓인 사람 관찰 데이터베이스.

믿음의 영역으로 쓰면 미신이고
자기 이해 도구로 쓰면 지도예요.

운전은 어차피 본인이 하는 거고요.
```

**8 (정직 훅)**
```
저희 가격표엔 '품절 임박' 같은 거 없어요.

대신 실제 판매량 카운터가 있고
10건 팔릴 때마다 1,000원씩 올라가요.

가짜 희소성 만들 바엔 진짜 숫자로 하려고요.
```

**9 (상식 훅)**
```
신년운세를 1월에 보는 건 사실 좀 늦어요.

사주의 해는 입춘(2월 초)에 바뀌거든요.
띠도 마찬가지고요.

그리고 흐름은 원래 미리 알아야 준비가 되죠.
```

**10 (링크 글 — 주 1회, 링크는 답글)**
```
사주 리포트 전문을 통째로 공개했어요.

보통은 결제해야 볼 수 있는데
그럼 뭘 사는지 모르고 사는 거잖아요.

가상 인물로 만든 실제 리포트예요. 다 읽어보고 결정하세요.
(링크는 답글에)
```
