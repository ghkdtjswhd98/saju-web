# 토스 계약심사 — 결제경로 캡처 가이드 (2026-09-06)

토스 계약팀(심서영B) 요구: 결제 경로 6단계를 **브라우저 주소창(도메인)과 PC 시간(작업표시줄 시계)이 함께 보이는 전체 화면**으로 캡처한 PPT.
카드사 인증 화면은 **비씨카드**로.

## 선행 조건 (순서대로)
1. 새 사업자등록증(파주 주소) PDF → `Desktop\오롭미\1_사업서류` 저장 → 클로드가 푸터 주소 대조·배포
2. 토스 개발자센터에서 **내 상점 테스트 키**(결제위젯용 클라이언트/시크릿) → Vercel 환경변수 교체
   - 지금 실서비스는 토스 문서 공용 테스트 키라, 승인 단계가 코드로 차단돼 "결제 시스템 오픈 준비 중" 화면이 뜸(6단계 캡처 불가)
   - 내 상점 테스트 키로 바꾸면 차단이 자동 해제되어 테스트 결제가 끝까지 진행됨
3. 배포 반영 확인 후 캡처
