## 7. 체험단 운영 (건당 3분)

1. 채팅에서 이름(별칭 가능)·생년월일시·성별 받기
2. 터미널에서 발급:
   ```
   npx tsx scripts/issue-tester-report.ts --name 홍길동 --birth 1995-03-15 --gender 여 --hour 14
   ```
3. 출력된 링크를 채팅으로 발송 + "다 읽으시면 맨 아래에서 후기 부탁드려요!"
4. 주문 없는 발급이라 후기에 "체험단 제공" 라벨 자동 (공정위 지침 자동 준수)
5. 미작성 3일 후 리마인드 1회만

## 8. 운영 리듬

- 소식은 주 1~2회 (콘텐츠:판매 = 2:1), 채팅 답장은 반나절 안에
- 후기 5개 쌓이면 사이트 후기 섹션이 자동 점등됨 → 그때부터 선순환
- 당근 정책: 외부 결제 링크 직접 유도 제한 가능 → 채팅으로 링크 발송 방식이 안전
