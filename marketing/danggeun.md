# 당근마켓 트랙 — 비즈프로필 + 무료체험단

## 1. 비즈프로필 개설 (1회, 10분)

1. 당근 앱 → 나의 당근 → 비즈프로필 만들기
2. 상호: 오롭미 / 카테고리: 기타(콘텐츠 서비스)
3. 소개글 (복붙):
   > 계산은 만세력으로 정확하게, 해석은 AI로 깊이 있게 🌙
   > 회원가입 없이 30초, 무료 사주부터 심층 리포트까지.
   > 사업자등록 완료한 동네 1인 콘텐츠 가게예요.
4. 프로필 이미지: 오롭이 캐릭터 (사이트 랜딩에서 캡처 또는 cards/ 커버 활용)
5. 사업자등록번호 입력: 281-42-01423

## 2. 무료 체험단 공고문 (복붙)

제목: **[무료] AI 심층 사주 리포트 체험단 10분 모십니다 (후기 조건)**

```
안녕하세요, 동네에서 사주 콘텐츠 서비스를 만들고 있는 오롭미예요 🌙

정식 오픈을 앞두고 심층 사주 리포트(정가 9,900원)를
무료로 받아보실 체험단 10분을 모십니다.

✅ 드리는 것
- 평생사주 종합 리포트 1건 (타고난 기질·재물·직업·연애·건강, A4 3~4장 분량)
- 결제 없이 링크로 바로 발급, 평생 소장

✅ 조건
- 리포트 받아보신 후 리포트 페이지에서 별점+한줄 후기 남겨주시기
- 후기는 "체험단 제공" 표기와 함께 사이트에 소개될 수 있어요

✅ 참여 방법
- 이 글에 댓글 또는 채팅으로 "체험단 신청"이라고 보내주세요
- 선착순 10분, 생년월일(+태어난 시간, 모르면 생략)만 알려주시면 돼요

⚠️ 저희는 팔자 계산을 만세력 데이터로 하기 때문에
"AI 사주는 팔자부터 틀린다"는 걱정이 없어요.
계산 결과는 아무 만세력 앱과 대조해보셔도 됩니다.
```

## 3. 체험단 운영 순서 (건당 3분)

1. 신청 채팅에서 생년월일시 받기
2. (운영자) 관리 스크립트로 리포트 발급 → 링크 복사
   - dev: `npx tsx scripts/issue-tester-report.ts --name 홍길동 --birth 1995-03-15 --hour 모름 --gender 여`
   - 주문 없이 발급된 리포트라 후기에 자동으로 "체험단 제공" 라벨이 붙어요 (공정위 지침 자동 준수)
3. 링크 발송 + "다 읽으시면 하단에서 후기 부탁드려요!" 한마디
4. 후기 미작성 3일 후 리마인드 1회 (그 이상 독촉 ❌)

## 4. 정식 판매글 (심사 후 결제 가능해지면)

제목: **사주, 계산부터 정확하게 — AI 심층 리포트 (오픈 특가)**

```
동네 이웃님들께만 먼저 소개해요 🌙

오롭미는 팔자 계산을 AI에게 맡기지 않아요.
만세력 데이터로 정확히 계산하고, AI는 해석만 합니다.

- 무료: 사주팔자 + 오행 + 성격 요약 (회원가입 없음, 30초)
- 심층 리포트: 평생사주 / 연애·궁합 / 올해운세 / 직업·재물 (오픈 특가 진행 중)

실제 판매량 기준으로 가격이 조금씩 오르는 정직한 가격제예요.
무료부터 편하게 해보세요 → [링크]
```
