[5] 네이버 검색광고 — 두 사이트 모두 랜딩 요건 충족 필요
- 2026-05-27부터 앱·웹 기반 운세 서비스는 조건부 허용: 개인 연락처(개인 휴대폰·개인 카톡ID) 노출 금지, 요금·환불·사업자정보·개인정보처리방침 명시, 효과 단정·불안 조장 문구 금지. ADVoost(자동확장)는 운세/사주/작명 업종 제한이라 파워링크 수동 소재로 운용. (출처: https://www.dmktnews.com/news/11692)

## 5. 오롭미 확장 설계 제안
■ 오롭미 확장 설계 제안

[전략 한 줄] 코드베이스와 계산·해석 엔진은 하나, 브랜드·도메인·결제·회원은 둘. 다만 마스코트 챗은 '별도 브랜드로 바로 출시'하지 말고 오롭미 안의 '수다방'으로 먼저 수요를 검증한 뒤 분리합니다(MID·카카오앱·도메인·브랜드 비용은 검증 후 지출).

[1] 두 서비스의 역할 분담
- 오롭미(리뉴얼): '계산은 만세력으로 정확하게, 해석은 AI로 깊이 있게' 본진. 가격대 6,900~19,900원 PDF 리포트 10종 + 무료 도구·SEO 페이지로 '다방면' 인상. 타겟 2030 여성, 궁합·연애·직업.
- 마스코트 챗(가칭, 브랜드명 미정): 990원대 저가 진입·매일 방문 습관·친구 공유 바이럴. 리포트는 챗 안에서 오롭미로 업셀. 사주아이(990원 원샷)와 타이트(2~7만 원 프리미엄) 사이 빈 가격대는 오롭미가, 사주아이·사주도령과 같은 990원 슬롯은 챗 브랜드가 맡습니다.

[2] 코드·인프라 — 모노레포 1개, 앱 2개
- 공유 패키지: lib/saju(만세력·flow-score·chemistry), lib/prompts(캐싱 프리픽스), lib/report-pdf, 결제 confirm 로직, 캐릭터 카탈로그(JSON), 크레딧 원장.
- 배포: Vercel 프로젝트 2개(orobmi / chat 브랜드) 또는 프로젝트 1개에 도메인 2개를 붙이고 middleware가 host로 브랜드를 분기. 초기(수다방 단계)는 후자, 분리 시점에 전자로 이동해도 코드 이동은 없습니다.
- Supabase 1개 프로젝트, 스키마에 brand 컬럼: profiles(생년월일 프로필, 익명/카카오 승격), orders(brand, mid, ch/ct/keyword 어트리뷰션), reports, chat_sessions, chat_messages, credit_ledger(reason enum: free_daily / purchase / referral / bundle / refund / consume, 유효기간), personas, stickers. 사주아이가 Firebase로 한 것과 같은 형태이며, 회원체계는 브랜드별로 분리(카카오 앱도 별도)하되 같은 DB 안에서 관리합니다.
- LLM 비용: 리포트는 Opus(원가 72~191원, 검증됨), 챗 1문답은 Haiku/Sonnet 급으로 20~60원 수준을 목표(정확한 단가는 claude-api 스킬로 재확인). 990원=10문답이면 1문답당 99원이라 마진이 남습니다. 근거 데이터(원국·대운·일진)는 결정론 계산으로 넣고 모델은 해석만 하게 해서 '만세력 틀림' 불만을 원천 차단합니다.

[3] 도메인·결제·로그인
- 도메인: 오롭미 커스텀 도메인(orobmi.kr, 미구입) 먼저 확보. 챗 브랜드는 분리 시점에 별도 .kr 도메인 구입(서브도메인도 토스 기준 별도 URL로 볼 수 있어 어차피 MID 추가 대상).
- 결제: 오롭미 MID 재심사 통과(9/10) → 챗 브랜드는 별도 랜딩(요금·환불·사업자정보·결제창)으로 MID 추가 발급. 챗은 토스 결제창 SDK v2 카드 + 카카오페이·네이버페이 간편결제(타이트와 동일 구성)로 990원 소액 결제 마찰을 줄입니다.
- 로그인: 두 브랜드 모두 무로그인 즉시 진입(Supabase 익명 세션) → 결제·보관·공유 시점에 카카오 로그인은 '혜택형 선택'(예: 로그인 시 문답권 +3회, 리포트 보관). 로그인 게이트 없음. 계정 승격 이벤트로 재방문을 측정합니다.
- 카카오톡 채널: 브랜드별 채널 1개씩. 챗 브랜드 채널은 오픈빌더로 '오늘 무료 수다권 충전됐어요' 알림·유입 용도, 실제 대화는 웹 채팅 페이지(결제·데이터 통제). 상담톡은 사람 응대가 필요해질 때만.

[4] 마스코트 설계 — 오롭이 활용 여부
- 권고: 챗 브랜드 마스코트는 새로 2종(공감형 + 직설형 2축)을 만들고, 오롭이는 챗 브랜드 안에서 '오롭미에서 온 친구' 카메오로 리포트 업셀·크로스 DM만 담당합니다. 이유: 오롭이는 '정확 계산' 본진 캐릭터인데 990원 수다 캐릭터로 쓰면 오롭미 포지셔닝이 싸 보이고, 반대로 두 브랜드가 완전히 단절되면 업셀 다리가 없습니다.
- 사주아이에서 가져올 장치: 캐릭터별 말투·환영 메시지·홈 티저 5종, 상황별 스티커 10~12종에 사용 조건 텍스트를 붙여 모델이 선택, 추천 질문 칩, '답변 작성 중' 상태, 최대 3명 프로필 동시 상담, 캐릭터 간 크로스 DM.
- 가져오지 않을 것: '35년 도사의 수제자' 같은 근거 없는 권위 장치(표시광고법 리스크). 대신 '만세력 원국 근거 카드'를 답변에 붙여 신뢰를 만듭니다. 오행 캐릭터 테스트(/test/ohaeng)와 일간 랜딩 10종은 챗 캐릭터 세계관에 그대로 재활용 가능합니다.

[5] 가격 모델 — 코인 vs 1회권 vs 구독
- 구독은 초기 배제(헬로우봇 월 26,000원 전환 후 헤비유저 이탈 사례, 사주아이·사주도령 모두 무구독). 이중 재화(츄르/냥)도 배제 — 후기에서 인지 부담 지적.
- 단일 재화 '문답권' 하나만: 무료 하루 1문답(무로그인, 매일 밤 자동 충전) / 990원 = 10문답(30일) / 2,900원 = 35문답(90일) + 오롭미 리포트 1,000원 쿠폰. 유효기간·미사용분 7일 환불·탈퇴 시 소멸을 약관에 명문화(사주아이 제11~12조와 같은 구조). 정가 표기 없이 실판매가만 노출, 오픈특가는 실제 종료일(LAUNCH_END)이 있을 때만.
- 자사 전용 포인트는 일반적으로 선불전자지급수단 등록 대상이 아니지만, 선물하기(제3자 이전)를 넣을 경우 전자금융거래법 해당 여부를 세무사·법무에 확인합니다.

[6] 무료→유료 전환 장치(정직한 것만)
- 오롭미: 무료 30초 결과 상단에 유료 리포트 실제 1문단 미리보기(이미 UpsellTeaser 3개 있음), 결과 페이지에 '생년월일 비공개 공유 링크' + '친구 사주 추가→궁합' 흐름, 이어 묻기 1회 무료 후 2회째부터 챗 브랜드 문답권으로 연결, 예측 성적표 적중률이 30건 넘으면 홈 위젯으로 노출(실데이터).
- 챗 브랜드: 오늘 무료 소진 시 '내일 밤 11시 충전' 또는 990원 즉시 결제 2택, 리포트 구매자에게 문답권 5회 번들, 친구 초대 시 양쪽 +3회(사주도령 귀인지도식 관계 분류는 chemistry.ts로 구현 가능), 수다 결과 카드(스티커+한 줄 운세) 카카오톡 공유.
- 두 브랜드 공통: 결제 전 환불·재발송 정책 노출, 후기는 토큰 보유자만·체험단 라벨 자동(이미 구현).

[7] 우선순위와 일정
- Phase 0 · 판매 시작 전(~9/30, 오픈특가 종료일까지): ① 토스 재심사 통과(9/10) ② 홈택스 정정(파주 주소 + 도메인, 부업종) ③ 9/6 결함 수정 6건 커밋·배포 ④ 오롭미 홈 프레임 리뉴얼(A안 톤 + 440 앱쉘 + 하단 탭 + 카테고리 탭·레일 3개 + 포스터 카드) ⑤ 약관·환불·개인정보처리방침 정적 페이지 정비(실사용 PG·AI 공급자 명기) ⑥ 무료 다방면 페이지 1차: 만세력 원국 보기, 일간 랜딩 10종 → 일주 60종 확장, 띠별·오행 테스트 ⑦ URL ch/ct/keyword → orders 저장(광고 시작 전 어트리뷰션).
- Phase 1 · 판매 후 4~8주(10~11월): ① 익명 세션 + 카카오 로그인 혜택형 + 보관함 ② 공유 링크·친구 추가 궁합 ③ 오롭미 안 '수다방' 베타(오롭이 + 신규 캐릭터 1종, 무료 1문답/일, 이어 묻기 확장) — 여기서 일 사용자·재방문·유료 전환을 측정 ④ 카카오톡 채널(오롭미) 개설·오픈빌더 알림.
- Phase 2 · 신년 시즌 전(11~12월, 수다방 지표가 좋을 때만): ① 챗 브랜드명·도메인 확정 ② 별도 랜딩 + MID 추가 ③ 카카오 앱 2호·비즈앱·채널 연결(2주 리드타임 감안해 11월 초 신청) ④ 캐릭터 2종+스티커 세트 ⑤ 문답권 원장·일일 리셋 크론·초대 링크 ⑥ 신년운세 상품을 두 브랜드에 동시 출시.
- Phase 3 · 2027 1분기: 네이버 검색광고(사전 보고 후), 예측 적중률 위젯, 프로그램적 SEO(띠별·일주별 궁합 페이지), 필요 시 앱쉘 웹뷰 안드로이드 앱.

## 6. 리스크
- 통신판매업 신고 면제 이탈: 990원대 챗 상품으로 거래 건수가 급증하면 일반과세 전환 시점(합산 매출 1억 400만 원 또는 파주 신주소의 2026 배제지역 해당 여부)에 두 사이트 합산 50회 기준으로 즉시 신고 의무가 생김. 사이트 분리로 회피 불가. (출처: https://www.law.go.kr/admRulLsInfoP.do?admRulSeq=2100000191541, https://blog.portone.io/ps_2026_simplified-vat_exclusion/)
- 토스 MID 계약 리스크: 오롭미 MID/클라이언트 키를 다른 도메인에서 쓰면 일시정지 소지. 챗 브랜드는 별도 랜딩으로 MID 추가 발급 필수. 현재 본 MID 재심사(기한 9/10)가 먼저 통과되어야 함. (출처: https://www.codemshop.com/guide/docs/identification-faq/)

saju-kid.com의 정식 브랜드는 '사주아이'로, 2025년 정현아 대표(전 인사혁신처 공무원, 비개발자)가 바이브코딩으로 3개월 만에 만든 1인 서비스이며, 인터뷰 기준 누적 수익 50억·회원 150만·거래 500만건을 광고비 0원으로 달성했다고 주장한다. 법적 주체는 한국 개인사업자 '사주아이'(411-31-52041, 통신판매 2025-서울노원-1503, 노원구 덕릉로 주소, 일반과세자)와 미국 워싱턴주 MindWise AI LLC(푸터 저작권·영문 랜딩·Stripe 해외카드)로 이원화되어 있고, 한국 사업자 개업일(2025-11-05)이 서비스 확산 시점보다 늦다. 기술은 Next.js 15 + Tailwind 3.4 + Firebase(Auth/Firestore/RTDB) + GCP 오리진 + Cloudflare 프록시, 분석은 GA4·PostHog·네이버 애널리틱스이며 앱스토어·플레이스토어 앱과 PWA는 없고 웹 전용이다. 결제는 토스(국내카드/간편결제)·카카오페이·Stripe·계좌이체 4종, 재화는 '츄르'(≈990원)와 '냥'(1츄르=3냥) 이중 구조로, 사주·궁합·대운·연도별·택일·자미두수를 개당 1츄르에 팔고 오늘의 운세는 하루 1회 무료, 채팅은 '무료 수다권' 매일 11시 1장 충전 후 1냥당 대화 3회로 과금한다. 디자인은 노랑(#F6C94D)·핑크(#E4568B) 브랜드 컬러, 448px 모바일 앱형 중앙 레이아웃, Pretendard 본문 + Jua/Orbit 디스플레이 + 명조 계열 리포트 폰트, 윈도우98풍 레트로 타이틀바와 하드섀도 요소가 특징이며, 복냥이(고양이, live)·햄스T(햄스터 고민상담, live)·타로·매화너굴이(신점, 예정) 캐릭터와 각 10여 종의 이모티콘 스티커로 카카오톡 채팅 감성을 자사 웹 채팅 안에서 구현했다(실제 카카오톡 채널은 홍보용). 마케팅은 인스타(팔로워 2천대에 불과)·X·네이버 블로그·카카오 채널을 걸어두고 Threads/더쿠/인스티즈/다음카페의 '내돈내산' 후기와 네이버 브랜드 검색으로 유입되는 바이럴 구조이며, 카피캣 대응용 '공식 주소' 안내 블록과 keywords 메타 도배가 눈에 띈다.

시사점:

- '사업자 하나로 여러 사이트' 질문에 대한 관찰 사실: 사주아이는 사업자 1개(개인사업자 사주아이)로 saju-kid.com을 운영하고, 영문 브랜드는 별도 미국 LLC로 두었다. 국내에서는 한 사업자 명의로 복수 도메인·브랜드를 운영하는 것 자체가 일반적이며(통신판매업 신고 시 도메인은 추가 신고 가능), 다만 오롭미는 '통신판매업 신고 면제(간이과세자)' 상태라 매출이 늘어 면제 요건을 벗어나면 두 사이트 모두 하나의 신고번호로 등록하면 된다는 점을 세무사에게 확인할 것(법률 판단은 본 조사 범위 밖).
- 디자인 참고점: 448px 고정폭 앱형 레이아웃, 브랜드 2색(노랑+핑크) + 파스텔 보조색, 카드형 상품 그리드(썸네일+한 줄 카피+가격 배지), 명조 계열 폰트로 리포트 본문을 '해설서'처럼 보이게 한 점은 무료→유료 전환 화면에 바로 적용 가능하다. 사주타이트의 '다방면 메뉴' 요구와 결합하면 상단 히어로 대신 상품 카드 그리드 + 하단 5탭이 현실적 템플릿이다.

### legal-pg
사업자등록 1개로 상호가 다른 여러 사이트·브랜드를 운영하는 것은 법적으로 문제가 없으며, 각 사이트 하단에 법적 상호('오롭미' 사업자등록증상 상호)와 사업자등록번호를 그대로 표기하고 새 사이버몰 명칭·도메인을 홈택스 정정신고로 추가하면 된다(사주타이트도 브랜드명과 상호 '사이버네틱스'가 다르다). 통신판매업 신고 면제는 '간이과세자' 또는 '직전연도 거래 50회 미만' 중 하나로 사업자 단위에서 판단되므로 간이과세자인 동안은 사이트 수와 무관하게 면제되지만, 일반과세 전환(연매출 1억 400만 원 초과 또는 2026년 확대된 배제지역 해당) 시에는 사이트별이 아닌 합산 거래횟수로 보는 것이 안전하며 즉시 신고가 필요하다. 토스페이먼츠는 '1 MID = 1 URL' 원칙이라 도메인이 다른 새 서비스는 상점아이디를 추가 발급받아야 하고(동일 사업자는 카드사 재심사 없이 발급, 단 심사용 랜딩 페이지에 사업자정보·약관·환불정책·결제창 필요), 등록 도메인 외 사이트에서 결제가 확인되면 일시정지 리스크가 있다. 네이버 검색광고는 2026년 5월 27일부터 앱·웹 기반 운세 서비스 광고를 조건부 허용하되 개인 연락처 노출 금지, 요금·환불·사업자정보 명시, 효과 단정·불안 조장 문구 금지를 요구하며, ADVoost 등 자동확장 상품은 운세/사주/작명 업종에서 제한된다. 카카오는 '앱 1개 = 서비스 1개(동일 회원체계)' 원칙이라 오롭미와 별도 회원체계의 마스코트 서비스는 각각 앱을 만들어 같은 사업자번호로 비즈앱 전환하고, 카카오톡 채널은 같은 사업자 소유 앱에만 연결되며 비즈니스 채널 전환과 3~5일 심사가 필요하다. 카카오 i 오픈빌더 챗봇은 무료이지만 외부 스킬 서버 연동에 비즈니스 채널(사업자)이 사실상 필요하고, 상담톡은 딜러사 계약이 필요하다.

시사점:

- 카카오는 서비스마다 앱을 분리: 오롭미(웹 로그인)와 마스코트 서비스(카카오톡 채널 챗봇)는 회원체계·약관이 다르므로 각각 디벨로퍼스 앱을 만들고 같은 사업자번호로 비즈앱 전환 → 비즈니스 채널 전환(3~5일) → 채널 연결 심사(3~5일) 순으로 최소 2주 리드타임을 잡는다. 동일 브랜드 안에서 앱을 여러 개 만드는 것은 운영정책 위반이다.
- 마스코트 챗봇 기술 스택: 카카오 i 오픈빌더(무료) + 스킬 API로 오롭미 Next.js 백엔드의 만세력·AI 해석을 재사용하면 개발비를 줄일 수 있다. 유료 심층 상담은 오픈빌더 응답에 결제 랜딩 링크를 붙이는 방식으로 시작하고, 상담톡(딜러사 계약·유료)은 상담원 응대가 필요해질 때 검토한다.

### market-voice
타이트사주(사이버네틱스, 2023년 창업, 10~11명)는 '웹툰 캐릭터(범산도령·무녀 피안) + 연애·재회·19+ 후킹 + 700개 URL 규모의 SEO 콘텐츠'로 2025년 월매출 10억원대, 재구매율 35%까지 성장했고 나는솔로런 협찬·소비자만족지수 1위 등 언론 노출로 브랜드를 쌓았습니다. 그러나 블라인드에는 '만세력·일간부터 틀림', 'GPT 복붙 같은 문장', '환불 어렵게 해둠' 같은 구체적 불만이 있고, 가격은 어느 랜딩에서도 노출하지 않는 미리보기 퍼널 구조라 가격 저항이 후기에 자주 등장합니다. 사주아이(1인 창업, 정현아)는 정반대로 8페이지짜리 단순 사이트에 '항목당 990원·자동결제 없음'만으로 회원 150만·거래 500만 건(자체 발표)을 광고비 0원으로 만들었고, 여초 카페·Threads에서 '8~90% 맞는다, 가성비 좋다'는 자발 후기가 많습니다. 다만 '70% 정도 체감, 지나치게 긍정적, 일반론, 신살 설명 장황, 무한로딩' 같은 아쉬움도 반복되며, 인스타 팔로워는 2K에 불과해 바이럴은 SNS 계정이 아니라 사용자 공유로 돌아갑니다. 복냥 채팅 페이지와 카카오톡 채널은 접근 차단(403)으로 요금·카톡 연동 여부를 확인하지 못했습니다. 카톡형 사주 챗봇 카테고리는 헬로우봇(2017년 메신저 챗봇 원조, 지금은 앱·월 26,000원 구독으로 이동해 헤비유저 이탈), 사주도령(2026년, 990원+하루 20회 무료 질문+친구 귀인지도 바이럴), 포스텔러(900만 가입·연매출 100억)·점신(콘텐츠/상담사 앱)이 있고, 사주톡톡·사주나루는 사람 상담 중개형입니다. 종합하면 사용자는 '싼 진입가·깔끔한 요점정리·캐릭터 몰입·친구와 공유'에 반응하고, '계산 오류·AI 티 나는 문장·환불 장벽·과잉 유료화'에 떠납니다.

시사점:
- 오롭미의 '만세력 기반 정확 계산'을 전면 차별점으로 내세울 것: 타이트사주 최다 불만이 '일간부터 틀림'이므로, 결과 페이지 상단에 원국표·절입시각·야자시 처리 기준을 투명하게 보여주는 것만으로 신뢰 소구가 됨(단, 진태양시·야자시 옵션은 실제로 검증 후 노출).
- '다방면' 확장은 타이트사주식 '상품 랜딩 20개+연예인 사주+블로그 SEO' 구조를 벤치마킹하되, 가격은 숨기지 말 것: 현재 6,900~19,900원 10종 라인업은 사주아이(990원)와 타이트사주(미공개 프리미엄) 사이의 빈 가격대이며, 990원짜리 '맛보기 항목' 1~2개를 추가해 사주아이식 공유 바이럴 진입점을 만드는 방식이 유효.
- 마스코트 카톡 챗봇 플랫폼은 '헬로우봇의 실패 지점(과잉 유료화)'과 '사주도령의 성공 지점(990원 후 무료 질문 20회, 친구 초대 무료 기능)'을 결합해 설계: 카카오톡 채널 챗봇 API는 2022년 9월부터 무료이므로 기술비는 낮고, 리포트 구매자에게 챗봇 후속 질문을 번들로 주면 오롭미 본체의 재구매·리텐션 도구로도 작동함. 단 복냥의 실제 요금·카톡 연동 여부는 미확인이므로 직접 결제해 UX를 확인할 것.
- 환불·장애 대응을 초기부터 공개 정책으로: 두 사이트 모두 '환불 어려움', '무한로딩'이 이탈 트리거였음. 오롭미는 '결과 생성 실패 시 자동 환불', 'PDF 미수신 시 1회 재발송' 같은 명문 정책을 결제 전 노출하면 소규모 사업자의 신뢰 열세를 메울 수 있음.
- AI 문장 품질 관리: 'GPT 복붙', '앞뒤 안 맞음', '지나치게 긍정'이 공통 불만이므로 리포트 생성 시 원국 데이터를 근거로 한 일관성 검사(같은 리포트 내 상반 진술 탐지), 부정 요소도 '주의점'으로 명시하는 톤 가이드를 프롬프트에 넣을 것.
- 복수 브랜드 운영: 타이트사주·사주아이 모두 한 사업자로 여러 도메인·채널을 운영하므로 브랜드 분리 자체는 관행상 문제없음. 다만 오롭미는 통신판매업 신고 면제 상태이므로 매출·거래 횟수가 늘면(특히 저가 챗봇으로 건수가 급증하면) 면제 요건 이탈 가능성을 세무사와 확인하고, 각 사이트 푸터에 동일 사업자정보·환불규정을 일관되게 게재해야 함.
