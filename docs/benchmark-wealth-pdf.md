## 2. 프롬프트 역추론 (사장님 질문의 답)

- **섹션 단위 생성**: 입력 = {이름·성별·생년월일시 + 그 섹션용 계산값 딱 3개} → 출력 = 정확히 3문단(문단 i ↔ 계산값 i 1:1 대응), 문단당 4~6문장
- **고정 텍스트와 LLM 분리**: "1번은 ~를 뜻합니다" 방법론 문단은 전 고객 동일한 정적 템플릿 — LLM은 개인화 3문단만 (토큰 절약)
- **이름 호명 강제**: 섹션당 "황선종님" 2~4회 — 후처리 치환 방식 (p19에 "{성함}님" 치환 실패 흔적)
- **긍정 마무리 강제**: 전 섹션 마지막 문장이 격려·안심으로 종결
- **용어 이중 구조**: 표에는 전문용어 노출(권위), 본문은 전부 풀어쓰기(평이) — 우리와 동일 철학
