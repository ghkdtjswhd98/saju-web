# 포스터 공식 — 압구정연애박사 45장 + 타이트사주 35장 분석 (2026-09-14)

> 방법: 5개 관점(구도·색/조명·타이포·소재/화풍·카피)으로 80장 전수 분석 → 공통 규칙 → 오롭미 채택/변형/기각 → 상품 10종 레시피. 근거는 라벨(T=타이트 1~35, L=연애박사 1~45)로 인용. 자료: scratchpad/poster-study/sheet-tight.png, sheet-love119.png

## 1. 두 사이트의 결정적 차이
두 사이트의 결정적 차이는 '한 공식으로 통일된 웹툰 표지(타이트)' vs '상품별로 갈아입는 상담소 광고(압구정)'다.

1) 제목 위치·면적: 타이트는 세로 2:3 풀블리드 인물 위 하단 25~30%에 흰 명조 제목+질문 1줄(29/35, 83%: T28·T29·T33·T22·T17). 압구정은 상단 40~45%를 비운 텍스트 존에 프리픽스→제목→구분선→설명 2줄의 3~4단 스택(약 28/45, 62%: L3·L4·L34·L40·L1), 가로 3:2에서는 좌상단 정렬(L30·L12)로 바뀐다. 타이트는 '영화 포스터형', 압구정은 '광고 배너형'.

2) 화풍·인물: 타이트는 애니·웹툰 일러스트 단일 화풍(29/35), 인물 등장 83%, 얼굴 클로즈업·정면 응시·도발적 표정(T2·T24·T29·T33), 커플은 키스·포옹·10cm 이내(13/16). 압구정은 실사·포토리얼 우세(약 56%)에 3D(L34·L39)·실루엣(L45)·타이포(L14·L35~37)를 섞고, 얼굴이 보이는 장은 31%뿐이며 절반이 뒷모습·등돌림(L3·L15·L33), 무인물이 60%(L34·L40·L31·L38·L41). 커플 접촉은 손·이마가 최대치, 키스 0장.

3) 색·명도: 타이트 다크 57%, 압구정 라이트 62%. 핑크를 타이트는 남색·보라와 섞고(T30·T35·T20) 압구정은 단독으로 쓴다(L8·L10·L28). 금을 압구정은 글자·테두리 재질로(L34·L17·L40), 타이트는 인물이 든 오브젝트로(T29 왕관·T33 열쇠) 쓴다. 대비 확보도 타이트는 하단 페이드, 압구정은 흰 박스·pill·종이.

4) 타이포·카피: 타이트는 서체 2종·색 흰 기본·질문 '~까?' 반말 독백('너/우리/나'), 포스터 질문과 목록 문구가 같은 질문의 말맛 변주(T25·T29·T30). 압구정은 서체 6계열, '당신'+'~나요?/~드립니다' 존댓말 상담체, 상태 지목 pill('연락창 열었다 닫기를 반복 중이라면' L5)→헤드→약속형 설명('~부터 살펴봅니다' L35)의 카피 기술이 발달했지만 긴박·추궁형이 약 27%(L1 '놓치면 끝나버려요', L5 '매달릴수록 더 멀어집니다', L36 '자꾸 새는 패턴이 있습니까?')로 타이트(14%)보다 공포 의존이 높다.

5) 오롭미 결론: 뼈대(풀블리드 원화·하단 제목·서체 1종·질문 1줄·연도 오너먼트·하단 페이드)는 타이트에서, 위계와 카피 기술(상태 pill·약속형 한 줄·항목 나열·프리미엄 액자선·무인물 정물)은 압구정에서 가져오되, 타이트의 키스·도발·반말과 압구정의 핑크 단독·가짜 숫자·경고 뱃지·'당신' 상담체는 모두 버린다. 화풍은 어느 쪽도 아닌 '반실사 회화풍 1종'(T19 한국화 일러스트·L45 실루엣·L40 정물의 중간, 추정)으로 고정해 두 사이트 어디와도 겹치지 않게 한다.

## 5. 레이아웃 규격
■ 공통 원칙
- 원화 1장(세로 4:5, 텍스트 없음)을 두 비율에 재사용. 4:5는 그대로, 3:2는 원화의 중앙~하단 피사체가 우측 55%에 오도록 재단(L1/L6 방식). 모든 텍스트·오너먼트·프레임은 코드 합성 레이어.
- 서체: 제목 붓글씨 1종 고정(전 상품 동일), 보조 텍스트는 얇은 명조 1종, pill은 중간 굵기 고딕 1종. 총 3종 이내.
- 색: 흰 #FFFFFF(기본 글자), 금박 #FFE9A8(강조 단어·티어 제목·오너먼트), 밝은 예외 카드(marriage·year)에서만 진한 금 #C9A85C 글자 + 딥네이비 #0B1220 글자.
- 효과: text-shadow 0 2px 12px rgba(0,0,0,.55) 한 겹. 티어 상품(deep·bundle·lifetime) 제목만 흰→#FFE9A8 세로 그라데이션 + 약한 글로우(blur 8px, 투명도 35%). 외곽선·박스·3D 베벨 금지.

■ 세로 4:5 (홈 캐러셀·레일) — 기준 1080×1350
- 오버레이: 하단 32% 구간에 linear-gradient(transparent → rgba(11,18,32,.55) 50% → rgba(11,18,32,.92) 100%). 상단 12%에도 rgba(11,18,32,.25) 얇은 페이드(뱃지 가독용).
- 안전 여백: 좌우 7%, 하단 6%.
- 텍스트 존(하단 28%): 3줄 세로 스택, 중앙 정렬.
  1) pill: outlined 캡슐, 테두리 1px #FFE9A8 60%, 배경 rgba(255,233,168,.08), 고딕 22~24px, 12~18자, 제목 위 14px.
  2) 제목: 붓글씨, 캔버스 폭의 72~85% 자동 맞춤(2~6자), 높이 약 110~140px, 흰색. 티어 3종은 금 그라데이션.
  3) 질문: 얇은 명조 34~38px(제목 높이의 약 0.3), 10~16자 1줄, 강조 단어 1개만 #FFE9A8.
- 연도 모듈: 제목 바로 위 중앙, 세리프 '2026' + 좌우 얇은 금박 구분선(1px, 폭 각 60px). year 상품은 제목의 0.6배, 그 외 시즌 태그가 필요할 때만 0.3배.
- 뱃지: 좌상단 8% 지점, outlined 캡슐 1개만(예: '풀패키지', '2026'). 빨간 경고·할인율·가격 뱃지 금지.
- 프레임: deep·bundle·lifetime만 안쪽 4% 위치에 1px #FFE9A8 60% 액자선, 네 모서리 단순 곡선+점 오너먼트(L40 문양 복제 금지). deep은 원형 창 옵션(지름 캔버스 폭의 70%, 중심 y 42%).
- 워드마크: 하단 6% 여백 안 우측, 'OROBMI' 세리프 18px, 흰 50%.

■ 가로 3:2 (목록·OG) — 기준 1200×800
- 오버레이: 좌측 48% 구간에 linear-gradient(90deg, rgba(11,18,32,.92) 0% → rgba(11,18,32,.6) 60% → transparent 100%). 피사체는 우측 55%에 위치.
- 텍스트 존: 좌측 42%, 세로 중앙 정렬, 좌정렬. 2줄까지만.
  1) 프리픽스(pill 문구를 pill 없이 얇은 명조 20px로) 또는 연도 모듈(0.3배).
  2) 제목: 붓글씨, 존 폭의 90% 자동 맞춤, 높이 약 90~110px.
  질문은 넣지 않고 카드 밖 subtitle로 이동(L30·L38·L13 규칙).
- 프레임: 티어 3종만 좌측 텍스트 존을 감싸는 얇은 금박 ㄷ자 라인(상·좌·하), 우측은 열어 둠.
- OG 안전 영역: 상하 8% 여백(SNS 미리보기 재단 대비, 추정).

■ 카드 밖 문구(제품 subtitle)
- 약속형 1줄 8~16자('~부터 봅니다/읽습니다' 또는 항목 나열 '시기·배우자·결혼생활의 결'). 이모지·느낌표·물결 없음.

■ 금지 목록(코드 레이어 포함)

## 6. 상품 10종 레시피

한 세트로 보이게 하는 규칙:
- 화풍 1종 고정: 10장 모두 '반실사 회화풍(한국화 결의 디지털 페인팅)'으로 생성. prompt 접두어의 화풍 문장을 한 글자도 바꾸지 않고, 애니풍(T-계열)·포토리얼(L-계열) 어느 쪽으로도 기울지 않게 동일 시드 계열·동일 생성기 설정을 유지한다.
- 바탕 남색 계열 통일: 8장은 딥네이비 #0B1220→#1F3A5F, year는 하단 남색→상단 새벽 하늘색, marriage는 상단 아이보리→하단 남색, dohwa는 자주-남색 #4A1F2E→#0B1220. 어떤 장이든 하단 30%는 반드시 딥네이비로 끝나야 10장 그리드에서 같은 페이드 리듬이 보인다(밝은 예외 2장도 하단은 남색).
- 광원 1개·방향 명시: deep 좌상단 달빛 / bundle 하단 발광 / lifetime 역광 빛기둥 / year 지평선 역광 / career 스탠드 램프 / reunion 창밖 별빛 역광 / crush 달빛 측광 / love 달빛 반역광 / marriage 창 역광 하이키 / dohwa 노을 역광. 광원 2개 이상이 생성되면 재생성.
- 원화 텍스트 제로: 고서 표지·족자·명함·나침반 문자반·휴대폰 화면·편지봉투 등 '글자가 있을 법한 소품'은 프롬프트에 '글자 없음'을 소품마다 개별 명시했다. 생성 결과에 글자·숫자·워터마크가 1개라도 보이면 폐기.
- 제목 서체 1종(붓글씨) + 색 2종: 흰 #FFFFFF 기본, deep·bundle·lifetime 3종 제목만 흰→#FFE9A8 세로 그라데이션. 서체로 카테고리를 구분하지 않는다. 밝은 카드(year·marriage)도 하단 텍스트 존이 남색이라 흰 제목 그대로 — 진한 금 #C9A85C는 상단 뱃지 등 밝은 영역 위 글자에만.
- 강조 단어 1개 규칙: 질문 문장에서 대괄호 1개만 #FFE9A8. deep[흐름]·bundle[보면]·lifetime[물결]·year[흐름]·career[결]·reunion[흐름]·crush[있을까요?]·love[부딪힐까요?]·marriage[때]·dohwa[끌림]. 2개 이상 칠하지 않는다(L32 반례).
- 3줄 위계 고정: [outlined pill 상태문구] → [붓글씨 제목] → [질문 1줄 10~16자, 어미 '~까요?'/'~은?']. 설명문·약속형 문장은 카드 밖 subtitle로만. year만 pill과 제목 사이에 연도 모듈 '2026'(0.6배)이 추가된다.
- 티어 프레임: deep·bundle·lifetime 3종만 안쪽 4% 금박 1px 60% 액자선 + 모서리 단순 곡선·점(L40 문양 복제 금지). deep은 액자선 대신 원형 창 옵션 가능하나 둘 중 하나만. 나머지 7종은 프레임 없음. 좌상단 캡슐은 bundle('풀패키지')·year('2026') 2장에만.
