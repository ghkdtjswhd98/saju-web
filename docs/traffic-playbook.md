# 오롭미 트래픽 플레이북 (2026-08-30)

> 출처: "사주 자동화 부업" 강의(원현우) 자막 전문 분석 + social 스킬. 강사 수강생이 279만원+매출 20%를 내고 받는 구조를 우리는 자체 스택으로 구현한다.
> 스펙: docs/superpowers/specs/2026-08-27-product-expansion-design.md (상품 확장) 후속.

## 파이프라인 (딸깍 순서)

```
[대본 생성기] → CapCut 촬영/조립 → 4곳 재업로드 → 댓글 키워드 → (2단계: 자동 DM) → 사이트 → 결제 → PDF 자동발송(구현됨)
[쓰레드 생성기] → 하루 2~4개 복붙 발행 → 프로필 링크 → 무료 사주 → 업셀
```

## 도구 사용법 (노트북에서, 또는 폰 창구 세션에 "만들어줘" 한마디)

```bash
# 띠별 숏폼 대본 12종 (기본: 올해운세, 도사 말투)
npx tsx --env-file=.env.local scripts/generate-shorts.ts
# 재회 상품용, 특정 띠만, 언니 말투
npx tsx --env-file=.env.local scripts/generate-shorts.ts --product reunion --tti rat,horse --tone eonni
# 쓰레드 글 10개 (mix) / 테마 지정
npx tsx --env-file=.env.local scripts/generate-threads.ts --count 10 --theme reunion
```

출력: `marketing/shorts/날짜-상품/띠.md` (훅·타임코드 대본·CapCut 자막·캡션·고정댓글), `marketing/threads/날짜-테마.md`

## 운영 룰 (강의에서 검증된 것)

1. **영상 1개 → 4곳 업로드**: 릴스·틱톡·쇼츠·네이버 클립. 구독자 0이어도 판매 가능.
2. **매일 1개, 최소 한 달**: 10여 개부터 알고리즘 탑승. 초반 하루 2~3시간, 숙달되면 30분.
3. **광고는 무자본 수익 후**: 첫 100만원 벌면 그중 20~30만원 광고 재투자 (집행 전 ROAS 보고 필수 — 오롭미 원칙).
4. **브랜드는 오롭미 하나만**: 채널은 문어발 테스트, 재구매는 한 곳으로 수렴.
5. **1:1 상담 금지**: 전자동 판매 구조 유지 (확장성).

## 소비자가 반응하는 것 (강의 실측 + 우리 실측)

- 띠 지목 + 반말 직설 ("개띠는 새겨들어라") — 조회 30만·댓글 6천 영상들의 공통점
- "안 좋은 것도 솔직하게" 컨셉 — 우리 리포트 원칙(직설이 신뢰)과 일치
- 실제 시한 (절기·연말) — 가짜 마감 대신 진짜 날짜
- 댓글 키워드 유도 ("댓글에 재회 남겨") — 참여 + DM 트리거 겸용
- 분량 = 품질 시그널 (그쪽 50~122페이지 강조; 우리는 실측 이하 표기로 동일 축)
- 재구매 사다리: 연애→재회→궁합→결혼 (3개월 내 재구매 30~34%, 재구매자 평균 10회 — 카드사 데이터)
