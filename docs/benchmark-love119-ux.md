# 압구정연애박사 UX/UI 완전 해부 + 오롭미 결합 공식 (2026-08-30)

> 대상: https://love119.sajutalktalk.com (사주톡톡 플랫폼 입점몰, 강의 "사주 자동화 부업"의 강사 사이트)
> 방법: DOM 전수 추출 + 이미지 원본 8장 실물 분석 + 강의 화면 캡처(상세페이지·프로그램 UI) 대조

## 1. 사이트 구조 (실측)

```
홈 = [메인 배너 캐러셀 5장(전면 포스터)] → [연애박사 BEST 사주: 카드 13개] → [이런 사주는 어때요?: 카드 4개]
카드 = [포스터 썸네일(S3)] + [카테고리 H3(결혼운세/재회운세…)] + [서브카피 한 줄] + [50% 뱃지 + 가격]
카드 클릭 → 상세페이지 = ★카카오 로그인 게이트★ ("지금 내 결혼운💍, 바로 열어볼까요? [카카오 로그인]")
로그인 후 → 상세(강의 화면에서 확인): 섹션 티저 카드 + "현재 523명 보는 중" 토스트
           + 하단 고정 [카운트다운 타이머 + 할인 CTA 버튼]
```

핵심 발견: **상세페이지 이전에 로그인부터 받는다** — 카드(포스터)가 구매욕을 만들고, 로그인은 DB 수집
(카톡 채널 5~6만 단골의 입구). 우리는 반대로 무로그인 즉시 진입이 강점이므로 게이트는 **안 따라간다**.

## 2. 이미지 공식 (원본 8장 분석)

모든 상품 이미지가 "포스터"다. 공통 구조:

```
[① 상품별 무드 배경]  감정마다 팔레트가 완전히 다름:
    재회=새벽 침실 딥네이비 / 결혼=수채화 하늘색 / 연애=핑크 애니 일러스트
    도화살=버건디+실루엣+네온 / 신년=한국화 블루+붓글씨
[② 질문형 소문구]     "당신의 배우자가 궁금하신가요?" / "이 인연, 그냥 스칠까? 이어질까?"
[③ 대형 장식 서체 제목] 붓글씨·손글씨 캘리그래피 ("병오년 신년운세", "연애운세")
[④ 감정 트리거 오브젝트] ★재회: 카톡 알림 목업 "전 연인: 자니..?" (방금) — 최고의 한 수
[⑤ 뱃지]              "재회의 골든타임" / "2026 새해맞이" (장식 프레임)
```

카피 패턴: 제목 위엔 항상 **질문**, 제목 아래엔 **긴박/약속** ("지금 놓치면 끝나버려요").

## 3. 상세페이지 공식 (강의 화면 캡처 기준)

- 섹션 티저 카드 나열: "내 강점은 어디에 쓰일까 — 막연한 재능이 아니라 일·관계·생활 속에서…"
- **정직 포지셔닝 카피 실재**: "불안한 말에 휘둘리고 싶지 않다 — 겁을 주고 무언가를 더 사게 하는
  풀이 대신, 이해와 준비를 남깁니다" ← 15억 매출 사이트가 우리와 같은 컨셉을 씀 (방향 검증)
- 하단 고정: 카운트다운("할인 마감까지 00:13:12") + 풀와이드 CTA "할인 받고 지금 바로 운세보기"
- "현재 523명이 보고 있어요" 실시간 토스트 (진위 불명 — 우리는 가짜면 금지)

## 4. 오롭미 결합 공식 (채택/기각 결정표)

| 요소 | 결정 | 구현 |
|---|---|---|
| 포스터형 상품 이미지 | ✅ 채택 | `/brand/poster?product=…` 자체 생성 (Satori, 상품별 아트 디렉션 10종) |
| 질문형 소문구+붓글씨 제목 | ✅ 채택 | Nanum Brush Script 서브셋 로드, ARTS 테이블 |
| 카톡 알림 목업 (재회 "자니..?") | ✅ 채택 | 재회="자니..?", 짝사랑썸="(입력 중...)" |
| 홈 2섹션 분할 (BEST/연애) | ✅ 채택 | "오롭미 BEST 사주" + "연애가 고민이라면" |
| 카드 = 이미지+카테고리+제목+가격 | ✅ 채택 | 홈·상품 페이지 전면 개편 |
| 카카오 로그인 게이트 | ❌ 기각 | 무로그인 30초가 우리 전환 무기 + 이메일은 결제 시 수집됨 |
| 상시 50% 할인 표기 | ❌ 보류 | 허위 정가 금지 — 토스 통과 후 "첫구매 쿠폰"으로 합법 구현 |
| 가짜 카운트다운·N명 보는 중 | ❌ 기각 | 원칙 위반. 실데이터 생기면 진짜 수치로만 |
| 로그인 기반 단골 DB | 🔁 변형 | 카톡 채널(개설 대기) + 완성 메일로 대체 |

이미지 저작권: 원본 이미지는 분석용으로만 사용. 실서비스 이미지는 전부 자체 생성(오롭미 브랜드).

## 5. 구현 내역 (2026-08-30)

- `app/brand/poster/route.tsx` — 상품 10종 포스터 생성기 (무드 그라데이션 + 붓글씨 + 뱃지 + 카톡 목업 + 트웨모지)
- `lib/og-font.ts` — 폰트 패밀리 파라미터화 (붓글씨 서브셋 로드)
- `app/page.tsx` — 홈 상품 그리드 → 포스터 2섹션 (BEST/연애)
- `app/products/page.tsx` — 각 상품 카드 상단에 포스터
