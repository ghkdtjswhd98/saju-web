# 상품 상세 페이지 v2 + 일러스트 포스터 (2026-09-13 사장님 지시: 타이트사주 벤치마킹)

## 벤치마킹 관찰(타이트사주 /marry, /solo, /money 실측)
- 히어로: 전면 일러스트(웹툰풍 인물) + 질문형 헤드라인 2줄("언제, 누구와 하게 될까?") + 가격 + 큰 CTA("시작하기"/"3초만에 미리보기") + 참여자 수(우리는 실데이터만).
- 감성 섹션: 그림과 한 문장("내 인생 일대 딱 한번의 결혼")이 번갈아 2~3회.
- 리포트 미리보기 = **챕터 카드**: 챕터 번호·제목 + 챕터 무드 일러스트 헤더 + "이 챕터가 답하는 질문" 3~4줄. 다크 카드, 카드 사이 여백 큼.
- 신뢰: 협업·수상 배지, 누적 숫자, 후기 카드. (우리는 진짜 것만: 만세력 계산·PDF 실측 페이지·실후기 수·크몽 후기 수)
- 하단 고정 CTA(가격 + 버튼) 유지.
- 우리와의 차이: 우리는 가격을 앞에서 보여주고(정직), 가짜 숫자·상시 할인·로그인 없음.

## 1. 일러스트 포스터(섬네일) — 10종
- 형식: 세로 4:5(600×750, 홈 캐러셀·레일) + 가로 3:2(900×600, 상품 목록·OG). 두 규격 모두 같은 원화(정사각 1024 또는 세로 1024×1280)에서 크롭.
- 스타일 통일 접두어(모든 상품 공통): "부드러운 웹툰풍 일러스트, 한국 20~30대 인물, 섬세한 선, 파스텔+딥네이비 대비, 밤하늘·별 모티프가 은은하게, 텍스트 없음, 로고 없음, 워터마크 없음, 얼굴 자연스럽게, 상반신 또는 실루엣, 여백은 아래쪽(제목 자리)".
- 상품별 장면(원화 프롬프트 초안, 타이트사주 구도 직접 복제 금지):
  - deep 정통 심층사주: 밤하늘 아래 한복 두루마리를 펼쳐 보는 청년, 금색 글자 빛
  - bundle 풀패키지: 세 장의 카드가 부채처럼 펼쳐진 손, 보라 안개
  - lifetime 평생사주: 별자리 지도를 올려다보는 사람 뒷모습, 인생 길이 이어진 밤길
  - year 올해운세: 붉은 말(병오) 실루엣이 달을 가로지르는 겨울 밤하늘, 눈송이
  - career 직업·재물운: 금빛 동전이 흩날리는 서재, 미소 짓는 인물 반측면, 초록 커튼
  - reunion 재회운세: 새벽 창가에서 폰 불빛을 바라보는 인물, 딥네이비, 창밖 초승달
  - crush 속마음운세: 카페 창가 두 사람, 한 명은 폰을 보고 한 명은 그 사람을 보고, 핑크오렌지 노을
  - love 궁합운세: 손끝이 닿을 듯한 두 손, 사이에 별빛 실, 은하수
  - marriage 결혼운세: 면사포 너머 미소, 창문 역광, 흰 꽃
  - dohwa 도화살: 붉은 꽃잎 흩날리는 밤, 자신감 있는 인물 실루엣, 버건디
- 타이포: 포스터 위에 붓글씨 제목·소문구는 기존 Satori 레이어로 합성(원화는 텍스트 없음). 하단 40%에 그라데이션 오버레이로 가독성 확보.
- 생성: scripts/gen-poster-art.ts — GEMINI_API_KEY(Google AI Studio, gemini-2.5-flash-image) 또는 OPENAI_API_KEY(gpt-image-1) 중 있는 것 사용. 상품당 3안 생성 → public/poster-art/{code}-{n}.png 저장 → 사장님이 고르면 {code}.png로 확정. 생성 원화는 저장소에 커밋(정적).
- 포스터 라우트(/brand/poster, /brand/poster-portrait)는 배경에 원화 이미지를 깔고 기존 텍스트 레이어 유지.

## 2. 상품 상세 v2 (app/products/[code]/page.tsx)
순서(430px 앱 셸, night):
1. 히어로: 세로 포스터 원화 전면(높이 ~62vh) 위에 그라데이션, 하단에 shortName 라벨 · 질문형 헤드라인(cardTitle 또는 hero_question 신규 필드) 2줄 · 실판매가(크게)+정가 · CTA "내 정보 입력하기"(금박) · 발급 시간·PDF 페이지 한 줄.
2. 감성 한 줄 섹션 ×2: 상품별 카피(lib/products.ts에 `moments: string[]` 신규, 2개) + 얇은 장식(별 SVG). 그림 없이 타이포로.
3. "이 리포트가 답하는 것들" → **챕터 카드**: sections를 챕터로(번호 01·02…), 카드 헤더는 상품 무드 그라데이션 + 작은 원화 크롭(원화 1장을 object-position 다르게 재사용) + 챕터 제목 + 질문 2~3개(기존 목차 설명 활용, lib/products.ts sectionsDetail 있으면 사용).
4. 샘플 미리보기 카드("결제 전에 샘플 먼저 보기" 유지).
5. 신뢰 스트립(진짜만): 만세력 계산 · PDF {pdfPages}p 실측 · 생성 실패 자동 환불 · 실후기 n건(0이면 숨김).
6. 후기(ReviewList) · FAQ 2~3개(상품 공통) · StickyBuyBar 유지.
- 가짜 참여자 수·수상 배지·협업 배지 금지. 가격은 처음부터 노출.
