# 수다방 베타 — 캐릭터와 카톡처럼 사주 수다 (2026-09-12 초안)

결정 배경: 사장님 "채팅 캐릭터는 사이트 안 수다방으로 먼저"(9/9). 별도 브랜드·결제 계약 없이 반응을 검증한다. 기준 조사: docs/competitor-tight-kid-2026-09-06.md(사주아이 복냥이).

## 1. 베타 범위 (검증용, 최소)
- 경로 `/chat`. 하단 탭 '수다방'의 "준비 중" 뱃지 제거·활성. 홈 수다방 티저 카드 → /chat 링크 + 버튼 "지금 수다 시작".
- 로그인 없음. 사주 정보는 **브라우저(localStorage)** 에만 저장(이름/별명·성별 선택·생년월일·시간). 서버에는 대화 세션 id와 사주 파생값(subset: 4기둥 간지·오행 분포·일간·대운 요약)만 저장 — 생년월일 원본 미저장(케미와 같은 원칙).
- **하루 1문답 무료**(브라우저 기준, 서버는 세션 id + IP 레이트리밋으로 보강). 소진 시 "내일 밤 11시에 다시 열려요" + 리포트 업셀 카드. **유료 문답권은 베타에서 만들지 않음**(수요 확인 후 990원=10문답 설계). 카피에 가격·구매 언급 금지.
- 캐릭터 1명(공감형). 이름·말투는 사장님 결정(기본안: "별이" — 밤하늘 별 정령, 따뜻한 반말 친구체 "~야/~해"). 오롭이는 답변 끝 카메오로 리포트 안내만("더 깊게 보려면 리포트에서 봐요").
- 답변 형식: 3~6문장 + **근거 카드 1개**(일간·오행 균형·올해 흐름 중 관련 항목, 계산값 그대로 표시) + 후속 질문 칩 2~3개. 부정 라벨·확정적 예언·의료/법률/투자 판단 금지(원칙 문서). 사주 밖 질문은 사주로 연결하거나 정중히 되돌림.

## 2. 화면
- 상단: 캐릭터 아바타(SVG, 밤하늘 톤) + 이름 + "오늘 남은 수다 1회".
- 첫 진입: 사주 미입력이면 별이의 첫 말풍선 "생일만 알려주면 네 원국 보면서 얘기해줄게" + PersonFields(별명·생년월일·시간, 성별 선택) paper 카드 → 저장 후 대화 시작.
- 대화: 카톡식 말풍선(상대=night 카드, 나=금박 배경 네이비 글자), 아바타, '답변 작성 중' 점 3개, 스트리밍 출력, 근거 카드(카드 안 표: 일간·오행 5막대), 추천 질문 칩("올해 연애운은?", "요즘 일이 안 풀려", "나랑 잘 맞는 사람은?", "이직 시기?").
- 무료 소진 상태: 입력창 비활성 + 안내 + 리포트 업셀(UpsellTeaser 3개 재사용 가능) + "친구 케미 순위" 카드.
- 공유: 답변 한 줄을 카드 이미지로 만드는 건 2차. 베타는 링크 공유만.

## 3. 백엔드
- 테이블: chat_sessions(id, saju_subset jsonb, nickname, created_at, last_seen), chat_messages(id, session_id, role, content, evidence jsonb, created_at). 하루 무료 카운트는 chat_messages(role=user, created_at 오늘 KST) count로 판단.
- API: POST /api/chat/sessions(person 입력 → computeAll → subset 저장 → {sessionId}), POST /api/chat/messages(sessionId, text → 권한/쿼터 검사 → 모델 호출 스트리밍 → 저장), GET /api/chat/sessions/[id]/messages.
- 모델: 기존 Anthropic 호출 코드(lib의 리포트 생성부) 재사용, 모델은 저비용(FREE_MODEL 환경변수 계열, 문답당 원가 ≤ 100원 목표). 시스템 프롬프트: 캐릭터 페르소나 + 원칙 + 원국 데이터(JSON) + 출력 스키마(본문/근거카드/후속칩 JSON 또는 구분자). 프롬프트 캐싱 프리픽스 활용.
- 계측: chat_start / chat_message / chat_quota_hit / chat_upsell_click.
- 성공 지표(2주): 진입→첫 질문 ≥40%, 다음날 재방문 ≥15%, 소진 후 리포트 클릭 ≥5%.

## 4. 하지 않는 것
로그인 게이트, 유료 문답권(베타), 캐릭터 2명 이상, 스티커 팩, 카카오 알림, 부정 라벨, 가짜 인기 문구.

## 5. 결정(사장님, 2026-09-12)
- 캐릭터 = **별이** · 밤하늘 별 정령 · 따뜻한 반말 친구체로 확정. 변경 사항 생기면 사장님이 알려주기로 함.
