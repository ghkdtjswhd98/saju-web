# 도령 바이럴 조사 — 오롭미 이식안

## 1. 도령은 정확히 무엇이었나 (사실 요약)

**확실한 것**

- '도령'의 실체는 네이티브 앱이 아니라 모바일 웹서비스 **'사주도령'(doryeong.app)**. 앱스토어/구글플레이 리스팅 없음. 운영사는 헤일메리(Hailmary, 대표 이수환), 서울 성북 소재 개인사업자 추정 규모의 1인 서비스. 도메인 등록 2026-05-01, 통신판매업신고 2026년 — 출시 3~4개월 차 신생 서비스다.
- 바이럴된 기능은 무료 기능 **'귀인지도'**: 방장이 별명+생년월일(시)로 지도를 만들어 전용 링크(doryeong.app/n/코드)를 뿌리면, 친구가 로그인 없이 별명+생일만 입력하는 즉시 방장과의 **케미 점수**(관찰 범위 68~88점)와 **오행 상생상극 기반 관계 5종**(귀인/단짝/내 사람/오른팔/호랑이 선생)을 받고 지도에 올라간다.
- 시각화는 밤하늘 배경에 중앙의 달('나')과 궤도 거리 위 오행 색 별('친구들') 구조. 화면 문구는 "달에 가까울수록, 별이 밝을수록 케미가 좋은 사람". 사용자가 기억하는 '태양계 행성'은 이 화면의 근사 기억이다(친구 별에 목·화·토·금·수 글자가 붙어 행성 인상을 줌).
- 확산 장치가 의도적으로 설계돼 있다: 공유 링크에 `utm_campaign=viral_network` 계측, 지도마다 동적 생성되는 개인화 OG 카드("OO님의 귀인 지도 — 생일만 넣으면, 내가 어떤 사람인지 나와요 · 나도 보기"), 참여자에게 '내 지도 만들기' CTA, 방장에게 'N명 올라왔어요' 카운터, 케미 순위표(금·은·동 메달).
- 수익화는 무료 귀인지도를 훅으로 쓰고 결과 화면 안에 **궁합 990원, 도령에게 질문 1회 330원** 등 저가 단품을 업셀하는 구조.
- 실사용 증거: 2026-08-14 X에서 일반 유저의 지도 링크 공유(28명 참여, 조회 1.5천), 답글에서 "애배 3명이 귀인", "호랑이선생님들 진짜 많다" 등 결과 라벨이 밈처럼 소비됨. 사용법 블로그가 2026년 8월에 집중 게시됨(검색 수요 발생 증거). 체인지로그 8월 중순 연속 갱신, '참여자 많은 지도 탈퇴 실패' 수정 기록 = 부하 징후.

**추정인 것**

- 바이럴 시기는 2026년 7월 말~8월 중순 시작, 조사 시점(2026-08-17) 기준 진행 중. 수 주밖에 안 된 스파이크라 **지속성(반짝 vs 롱런)은 아직 판정 불가**.
- 인스타 스토리에서의 구체적 확산 형태(지도 캡처 + 링크 스티커 조합으로 추정)는 스토리의 휘발성 때문에 직접 증거 미확보. 더쿠·인스티즈·틱톡 흔적도 인덱스에서 미검출(부재 단정은 불가).
- MAU·참여자 총수 등 정량 규모는 웹서비스 특성상 확인 불가. 규모 흔적은 SNS 공유량뿐.
- '전원 승자 설계(낮은 점수도 긍정 역할로 포장)가 확산의 핵심'이라는 해석은 결과 문구 관찰 기반이며 사용자 인터뷰 근거는 없음.

## 2. 바이럴 공식 분해 (왜 스토리에 올리고 싶어지나)

심리 단위로 쪼개면 7개 장치다. 도령은 이걸 전부 갖췄고, 유사 사례(vonvon, NGL/Gas, 썸원, Wrapped)와도 일치한다.

1. **수신자 마찰 제로** — 링크 받은 쪽이 30초 안에 끝난다. 로그인 없음, 별명+생일만, '태어난 시간 몰라요' 허용. 확산되는 쪽(수신자)의 마찰이 방장보다 낮아야 한다는 게 모든 성공 사례의 공통점.
2. **미완성 콘텐츠** — 내 지도는 친구가 들어와야 채워진다. 공유가 '선택'이 아니라 **콘텐츠 완성의 필수 단계**가 된다. 이게 단발 결과공유형 테스트와의 결정적 차이.
3. **호명(소환) 명분** — 결과가 상대를 지목하는 역할 라벨("넌 나한테 오른팔이래")로 나온다. 점수보다 라벨이 대화 소재가 된다는 게 X 반응에서 확인된 핵심. 공유 동기 3종(과시·애정표현·장난) 중 '장난+소환'을 정확히 때린다.
4. **전원 승자 프레임** — 최저점(68점)조차 '나를 키우는 호랑이 선생'이라는 긍정 역할. 나쁜 결과가 없으니 친구를 초대해도 관계가 상하지 않고, 올려도 자기에게 손해가 없다. 초대 부담 제거 장치.
5. **서열과 변동** — 케미 순위표(메달), 귀인 개수 카운트("귀인이 7명 — 복이 두터운 사람"), 새 참여자마다 바뀌는 랭킹. 이미 참여한 친구도 다시 들어오게 만드는 재방문 장치이자, "누가 1등 귀인인가"라는 화제성 엔진.
6. **스크린샷 찍고 싶은 낯선 시각화** — 밤하늘 지도라는 처음 보는 그림 + 확대하면 친구 별명이 보이는 구조(스토리에서 친구들이 자기 이름을 찾게 만듦). 결과 카드의 4요소: 별명형 칭호 + 비교 가능한 숫자 + 낯선 시각화 + 스토리 친화 비율.
7. **링크 자체가 초대장** — 붙여넣는 순간 개인화 OG 카드가 CTA("나도 보기")와 참여 방법("생일만 넣으면")까지 담아 펼쳐진다. 링크가 그냥 URL이 아니라 행동 유발 카드다.

그리고 이 루프 위에 얹힌 원칙 하나: **돈은 루프 밖에서 받는다.** 무료 루프가 만든 관계 호기심("우리 관계는 왜 이런가")을 330~990원 충동결제 가격대로 심화 해소한다. Gas의 주 $7 God Mode, 연애의 과학 건당 결제와 같은 지점이다.

## 3. 오롭미 이식안 3개

### 안 1. "봉인 궁합" — 상호성 장치 (필수 요건 충족안)

**구조**: 기존 궁합 모드(/?mode=couple)를 링크 기반 2인 플로우로 확장한다.

1. A가 자기 생일만 입력 → "봉인된 궁합"이 생성되고 초대 링크가 나온다. **A도 이 시점엔 결과를 못 본다** (티저만: "궁합이 봉인됐어요. 상대가 열어야 둘 다 볼 수 있어요").
2. B가 링크에서 생일 입력하는 순간 봉인 해제 — B는 즉시, A는 재방문 시 결과를 본다.
3. 결과 하단에 "나도 봉인 궁합 만들기" CTA.

썸원의 상호 잠금(둘 다 기여해야 공개)과 도령의 링크 구조를 결합한 것. 현재 궁합 모드는 한 사람이 두 사람 생일을 다 알아야 쓸 수 있는데, 봉인 구조는 상대 생일을 몰라도 시작할 수 있고, **링크를 보내는 행위 자체가 애정표현/떠보기가 된다** — 썸 단계 20대의 DM 확산에 정확히 맞는 형태.

**기존 코드 위에 얹는 방법**: 오행 케미 계산·궁합 로직 그대로 재사용. 신규는 (a) 초대 코드 1개당 A의 입력값+상태(봉인/해제)를 담는 저장소 테이블 1개(Vercel KV 또는 기존 DB), (b) /invite/[code] 페이지, (c) next/og로 동적 OG 카드("OO님이 봉인한 궁합이 도착했어요"), (d) 공유 링크 utm 계측.

**규모**: M (3~5일)

**예상 효과**: 궁합 모드가 1인 소비형에서 2인 전파형으로 바뀐다. 봉인 상태는 A의 재방문도 강제한다(결과를 보려면 돌아와야 함). 해제된 결과 화면이 유료 궁합 리포트 업셀의 최적 지점.

### 안 2. "인연 지도" — 다인원 귀인지도형 (본편 이식)

**구조**: 도령 귀인지도의 검증된 골격을 그대로 가져오되 표면을 차별화한다.

1. 방장이 생일로 지도 개설 → 전용 링크 → 친구가 별명+생일 입력 즉시 케미 점수+관계 라벨을 받고 지도에 올라감.
2. 관계 라벨은 기존 오행 케미 계산으로 산출하되 **오롭미만의 라벨 세트를 새로 작명**한다(도령의 귀인/오른팔/호랑이 선생 복제 금지 — 전원 긍정 프레임 원칙만 가져온다).
3. 시각화도 달/별 메타포를 피하고 오롭미 브랜드에 맞는 다른 그림(예: 오행을 다섯 색으로 쓰는 정원/계절 메타포 등)으로. 인원 카운터, 케미 순위, 라벨별 인원수 요약은 그대로 채택.

**기존 코드 위에 얹는 방법**: 오행 케미 계산 엔진 재사용(방장 일간 기준 상생상극 → 라벨 매핑 테이블만 추가), 일간 배지를 참여자 아이콘으로 재사용, 기존 1080x1350 카드 파이프라인을 지도 캡처 카드로 확장. 신규는 지도/참여자 데이터 모델, /map/[code] 페이지, 시각화 컴포넌트, 동적 OG, 별명 필터링.

**규모**: L (1~2주)

**예상 효과**: 참여자 전원이 잠재 방장이 되는 연쇄 구조라 셋 중 확산 상한이 가장 높다. 단, 구현이 크므로 안 1 또는 5장의 최소 실험으로 "오롭미 사용자층에서 링크 수신자가 실제로 입력하는가"를 먼저 검증한 뒤 착수할 것.

### 안 3. "스토리 초대 카드" — 기존 공유 카드의 초대장화

**구조**: 현재 공유 카드는 '이미지 저장'에서 끝난다 — 카드를 본 사람이 행동할 경로가 없다. 이를 초대장으로 바꾼다.

1. 기존 1080x1350에 더해 **9:16 스토리 비율 버전** 추가, 카드에 일간 배지+칭호+점수+짧은 링크를 박는다.
2. 모든 결과 페이지에 개인화 공유 링크 부여 + 동적 OG 카드("OO님의 사주 카드 — 생일만 넣으면 너와의 케미가 나와요 · 나도 보기").
3. 링크 수신 랜딩은 홈이 아니라 "당신은 OO님과 어떤 케미?" 즉시 입력 폼 → 입력 즉시 케미 점수 → "나도 내 카드 만들기".

**기존 코드 위에 얹는 방법**: 카드 생성 로직에 비율 1종 추가, next/og ImageResponse로 OG 라우트 1개, 오행 케미 계산 재사용. 수신 랜딩은 기존 무료 사주 입력 폼 재활용.

**규모**: S (2~3일)

**예상 효과**: 신규 기능 없이 기존 공유 행동의 전환율만 올리는 안. Wrapped·ktestone이 증명한 "스토리 비율 + 카드에 CTA 내장" 공식. 안 1·2의 기반 인프라(동적 OG, utm 계측, 수신 랜딩)를 겸한다.

**우선순위 제안**: 안 3 → 안 1 → (검증 후) 안 2. 안 3이 인프라를 깔고, 안 1이 상호성 루프를 검증하고, 지표가 나오면 안 2로 확장.

## 4. 하지 말아야 할 것

- **부정적 결과 노출 금지.** 궁합 점수가 낮게 나오는 조합을 그대로 보여주면 초대 자체가 위험 행위가 된다. 도령은 최저점도 긍정 역할로 포장했다. 오롭미 케미 계산 결과에 나쁜 라벨이 존재한다면 바이럴 플로우에서는 전부 긍정 프레임으로 재작성해야 한다.
- **링크 수신자에게 가입·로그인 요구 금지.** 오롭미는 이미 무가입 구조라 유리하다. 이 장점을 바이럴 플로우에서 훼손하지 말 것(예: '결과 보려면 가입' 삽입).
- **바이럴 루프 안에 유료 벽 세우기 금지.** 훅 기능은 끝까지 무료. 업셀은 결과를 다 보여준 뒤에만. 또한 오롭미 최저가 6,900원은 도령의 330~990원 같은 충동결제 가격대가 아니다 — 루프에서 곧장 6,900원으로 보내면 전환이 죽을 가능성이 높다. 990원대 마이크로 상품(예: "이 친구와의 케미 한 줄 심화 풀이")을 브릿지로 두는 것을 검토할 것.
- **생년월일 원본을 URL·공개 화면에 노출 금지.** 공유 링크에는 파생값(일간/오행)이나 서버 저장 코드만. 도령도 별명 권장·생시 비공개 기본·14세 확인으로 프라이버시 마찰을 체계적으로 제거했고, 연애의 과학은 관계 데이터 취급 부주의로 2021년 프라이버시 파동을 겪었다. 타인 생일 무단 등록을 유도하는 카피도 금지(블로그들이 공통 지적한 우려 지점).
- **도령 표면 복제 금지.** 밤하늘/달/별 메타포, 귀인·호랑이 선생 라벨명을 그대로 쓰면 아류 인식+분쟁 리스크만 남는다. 검증된 것은 구조(링크→저마찰 입력→긍정 라벨→서열→재생산)이지 표면이 아니다. 도령 스스로도 동명 역술인과의 혼동 문제를 겪고 있다.

**실험명: 케미 초대 링크** — 안 3의 최소 절편이며 안 1·2의 선행 검증.

**측정과 판정 (1~2주 관찰)**:
- 핵심 지표는 K-factor 근사치 = (링크 유입→입력 완료 전환율) × (입력 완료→재생성 전환율).

이 실험은 새 계산 로직도, 저장소도, 유료 변경도 필요 없다. 이미 있는 오행 케미 계산과 입력 폼에 링크·랜딩·OG·계측 네 조각만 얹는 것이며, 실패해도 잃는 것은 하루의 코드뿐이다.
