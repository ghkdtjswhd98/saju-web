# 오롭미 리포트 출력 개선안
— 4개 각도 조사(SNS 공유 패턴 / 커뮤니티 후기 / 경쟁 서비스 / 유형 테스트 문화) 종합

---

## 1. 재미의 공식 (우선순위순)

### ① 검증 가능한 구체성이 "소름"을 만든다 — 최우선
일반론("당신은 좋은 사람")이 아니라 사용자가 자기 삶과 대조할 수 있는 구체적 진술(직업 성향·시기별 사건)이 반응의 핵심 트리거.
> 근거: "이 분이 내 인생을 보셧나; 싶을 정도임", "내 직업이랑 대학이랑 과도 맞추고" (더쿠 공포게시판, theqoo.net/horror/857870861). 더쿠에서 '소름' 후기 제목만 9건+, 본문 확인 3건 전부 구체적 사실 적중 인용.

### ② 직구가 덕담을 이긴다
껄끄러울 정도로 덤덤한 단점 지적이 신뢰를 만들고, 좋은 말만 가득하면 자동답변으로 의심받는다. 긍정·부정 사례가 정확히 대칭으로 관찰됨.
> 근거: "성격도 좀 내가 보기 껄끄러워질 정도로 덤덤하게 직구날리면서 맞춤" (더쿠, 긍정 이유) vs 점신에 대해 "좋은 말만 가득" (네이트판 pann.nate.com/talk/336819925, 부정 이유).

### ③ 공유되는 것은 결과 전체가 아니라 "한 문장"
예언체가 아니라 '나는 ~한 사람' 자기서사체 한 줄이 잘려서 공유된다.
> 근거: "2025년 12월 사주 한 줄 정리 — 나에게 안정적인 감정을 선물해주는 사람이 있다면…" (Threads @seeuwithin, 조회 2.9K), "친구가 해석해 준 세븐틴 사주 한 줄 평" (X @ssamjal_). '한 줄' 키워드가 사주 공유 문맥에서 반복.

### ④ 시간 구조가 재방문과 후기를 만든다
"전반은 어렵고 후반에 풀린다" 같은 시기별 예측은 사후 검증이 가능해서, 맞으면 자발적 후기 글이 나온다. 소름과 "끼워맞추긴가??" 의심이 공존하는 것 자체가 놀이.
> 근거: "금전은 처음은 어렵고 후가 좋다, 취직은 된다" → 본인 검증 "하반기 통장에 돈 쌓이고 있고" (더쿠 theqoo.net/review/616129397). "좀 소름이였어… 끼워맞추긴가??" (theqoo.net/review/211780183).

### ⑤ 유형명 + 별명 + 퍼센트 바 = 캡처 단위
16 Personalities의 성공 공식: 유형코드+별명(INFP '중재자')+캐릭터+지표 퍼센트 막대를 한 화면에 담고, 그 화면이 캡처·공유 단위가 된다. 한국형 히트작(테토·에겐)은 유형 수를 4개로 극단적으로 줄이고 밈형 이름을 붙였다.
> 근거: 나무위키 16 Personalities 문서(결과 화면 구성 + "밈으로 활발하게 도식화"); 서울교대학보: '테토'·'에겐' 언급량 전년 대비 200%+ 증가.

### ⑥ 바이럴 루프는 "남 결과 궁금증"
검사 경험자의 71.2%가 지인 결과를 궁금해하고 63.3%가 직접 권유(트렌드모니터 설문). 궁합·비교 장치가 이 루프를 태운다. 앱 후기에서도 "궁합>연애스타일 진짜 잘맞음"이 조회 27만 글의 핵심 문장(Threads @arcanedrop).

### ⑦ 팔자 표 자체가 유통되는 오브젝트
만세력 캡처를 GPT에 올려 풀이받는 워크플로가 장르화됨(Threads·X 3회 독립 관찰). 표 이미지가 서비스 밖으로 들고 다녀지는 과정이 곧 노출이다.

### ⑧ 질문형 카피와 유형화 콘텐츠가 유입 상위
경쟁 3사(포스텔러·청월당·점신) 전 상품이 "~일까?" 질문형 부제. 포스텔러 조회수 상위(300만~600만)는 전부 유형화·지수화 콘텐츠('매력지수', '60갑자 동물').

## 3. 프롬프트로 되는 것 vs UI로 되는 것

**프롬프트 수정만으로 (배포 즉시, 총 ~1일):**
- 한줄요약 → 자기서사체 1인칭 전환
- 성격카드 직구 1줄 의무화
- 올해힌트 시간 구조(상/하반기 대비)
- 유료: 과거 적중 섹션 강화, 직구 톤, 질문형 소제목

**UI/개발 필요 (총 ~3-4일):**
- 일주 이름 대문 노출 + 일간 별명 레이어 (계산 데이터 + 정적 매핑)
- 팔자 표 / 결과 카드 이미지 저장 (워터마크 포함)
- 유료 목차 공개 + 본문 잠금 레이아웃
- 궁합 매핑 테이블 + CTA

**프롬프트로 하면 안 되고 데이터로 해야 하는 것:**
- 별명·유형·궁합은 LLM 생성이 아니라 **결정론적 매핑**이어야 함 — 같은 일간인데 별명이 매번 다르면 유형으로서의 정체성(라벨링 게임, 소속감)이 성립하지 않고, 친구끼리 비교 시 "복붙 아닌데 왜 달라?"의 역방향 불신이 생김.

## 4. 하지 말 것

1. **지어낸 "상위 N%" / 확률 수치** — 청월당·점신에서 관행으로 관찰됐지만("내 사주는 상위 몇 %?", "재회확률"), 오롭미의 '지어낸 수치 금지' 원칙과 정면 충돌. 굳이 하려면 60갑자 중 일주 출현 빈도처럼 실제 계산 가능한 희소성만, 산출 근거 명시와 함께. 근거 없는 %는 금지.
2. **덕담 일변도** — "좋은 말만 가득" = 자동답변 의심의 직접 원인 (네이트판).
3. **조합 간 문구 재사용** — 사용자들이 실제로 서비스·결과 간 문장을 줄 쳐가며 대조함. 복붙 발각 = 즉시 낙인 + 타 서비스 추천 이탈 (네이트판 댓글).
4. **가짜 실시간 리뷰/이용자 수** — 청월당식 리뷰 스트림은 효과가 관찰됐지만 후기 0건인 오롭미가 흉내 내면 조작이며, 발각 시 "만세력 검증 가능성" 정체성 전체가 무너짐.
5. **유명인 사주 매칭 (생시 포함)** — 유명인 생시는 비공개라 대부분 추정이 됨. 나무위키조차 "연예인이 밝힌 MBTI는 믿을 게 못 된다"고 지적. 쓰려면 생년월일 공개 인물의 **일간까지만** + "생시 미상, 일간 기준" 명시.
6. **'과학적 정확성' 주장** — 불필요. "재미로 본다(64.4%)"와 "믿는다(75.2%)"가 공존하는 소비 태도가 검증돼 있어, 전통 명리 계산 근거의 정직한 표기 + 가벼운 문구만으로 충분히 소비됨.
7. **모든 유형에 캐릭터 일러스트부터 발주** — 캐릭터 페르소나(청월당)는 효과 관찰됐으나 일러스트는 비용이 크고, 텍스트 별명 레이어만으로 먼저 반응을 확인할 것.

## 5. 확인 못 한 것

- **캡처 이미지의 실제 내용물**: 인스타·틱톡 로그인 장벽으로, 사람들이 올린 결과 캡처에 정확히 무엇이 담겼는지(별점? 표? 문장?) 시각 확인 사례 0건. "한 장 카드가 공유 단위"라는 결론은 텍스트 공유물과 16P 문서 서술 기반의 간접 추정.
- **별점/점수 숫자의 공유 여부**: 별점 캡처 공유 사례 직접 관찰 못함. 현재 오롭미 별점 5종이 공유를 유발하는지는 미검증 — 결과 카드에 넣을지는 A/B 필요.
- **1:1 친구 비교 원문**: "내껀 이런데 네껀?" 형태의 직접 증거 없음(설문 수치와 커뮤니티 단체 공유로 간접 확인).
- **경쟁사 결과 화면 내부**: 결제·로그인 장벽으로 상품 페이지·목차·리뷰 기반 간접 추정. 헬로우봇·미스틱데이 미방문.
- **990원 후기의 실제 내용**: 제목만 관찰. "저가 = 가벼운 공유 소재" 구조는 게시물 내부 미확인.
- **더쿠 대형 글 댓글 1,772개의 실제 내용**: 규모만 확인, 댓글 원문 렌더링 불가.
- **김씨네 테스트·본초비담**: 검색으로 실체 확인 불가.
