### 오늘 만든 것

#### 1. 리포트 PDF 발송 (당근 판매의 핵심)
- `/report/{토큰}/pdf` — A4 PDF 자동 생성. 표지(사주팔자 표 + 오행 + 대운 시간표) → 전 섹션 → AI 고지 페이지
- 한글 폰트를 CDN에서 런타임 로드해 임베딩. 실측 10페이지 63KB
- 리포트 페이지에 "📄 PDF로 저장하기" 버튼
- **당근 채팅에 파일 그대로 첨부해 보낼 수 있습니다**

#### 2. 운영자 콘솔 `/admin`
- 정보 입력 → 발급 → 생성 → PDF·링크까지 **한 화면에서 1~2분**
- "💰 입금 완료(실판매)" / "🎁 체험단 무상" 구분
  - 실판매: 주문이 기록돼 후기에 "구매 확인됨" 라벨 + 판매 카운터 반영
  - 체험단: 주문 없이 발급 → 후기에 "체험단 제공" 자동 표기(공정위 지침 준수)
- 채팅 발송 문구 자동 생성, 최근 발급 목록
- 첫 접속 시 관리자 키 한 번 입력하면 브라우저에 저장됨 (키는 `.env.local`의 `ADMIN_KEY`)

#### 3. 공개 샘플 페이지 `/sample`
- 실제 발급된 리포트 **전문을 통째로 공개** (가상 인물)
- 경쟁사 8곳 조사 결과 **전문을 공개하는 곳은 한 곳도 없었습니다** → 검증된 유일 차별점
- 당근 채팅 첫 답장에 이 링크만 보내면 설득이 끝납니다

#### 4. 프리미엄 상품 신설 — 정통 심층사주 19,900원
- 12개 섹션 · PDF 18페이지 · 14,000자 · **10년 단위 대운 흐름을 구간마다 서술**
- 실생성 검증 완료 (9세~68세 대운 구간별 서술 확인)
- 이유: 당근 상위 업체 실측 가격이 2만~4.5만원인데 우리 최고가가 17,900원이라 사다리 상단이 비어 있었음

#### 5. 전환 카피·신뢰 장치 전면 교체
- 후기 헤드라인을 "★ 5.0 · 후기 12건" 형태로 승격 (상위 판매자 공통 패턴)
- **생성 전 100% 환불** 명문화 + 환불 제한 이유를 샘플 공개와 논리 연결
- 상품 카드에 "PDF n페이지 · n자 분량 · 1~2분 즉시 발급" 뱃지
- 랜딩 카피: "더 깊이 알고 싶다면" → "무료로는 안 보이는 것", "오롭미가 다른 이유" → "챗봇 사주는 왜 팔자부터 틀릴까요"

#### 6. 마케팅 자산
- `marketing/sale/` — 상품 판매 썸네일 6종 (1080×1080, 정가 취소선 + 페이지 수 + 즉시 발급)
- `marketing/sns-playbook.md` — 인스타·스레드 운영 매뉴얼 (릴스 대본 5개, 후킹 문구 20개, 스레드 글 10개, 30일 캘린더)
- `marketing/danggeun.md` — 가격 사다리·채팅 스크립트 갱신
