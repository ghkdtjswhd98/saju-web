## 1. 한눈에 보는 결론 5가지

### ① 소식은 다작이 아니라 **대표글 1개 몰빵**이다
문의 데이터가 있는 9곳 중 **7곳에서 대표글 하나가 전체 문의의 96% 이상**을 만든다(중앙값 99.1%).
가장 극명한 대비 — 명리직설은 **글 1개**(183,915조회·4,600문의)로 삼성명리 **10글 전부**(15,472조회·101문의)보다 조회 11.9배·문의 45.5배를 냈다.

### ② 제목에 가격이나 단품명을 박으면 전환이 **9.4배**다
조회 1만 미만 구간(조회수 차이를 통제한 가장 깨끗한 비교):

| 제목 유형 | 전환율 중앙값 | 표본 |
|---|---|---|
| 가격·단품명 있음 | **8.91%** | 4글 |
| 없음 | 0.95% | 27글 |

유형별로 보면 단품 상품명형 8.19% > 이벤트·가격형 6.96% > 역설형 2.96% > 선언형 1.37% > 질문형 1.36% > 공지형 0.90% > **정보성 지식글 0.83%**. 최고와 최저가 9.9배.

### ③ 납기 슬롯이 **텅 비어 있다** — 우리의 가장 큰 미점유 칸
발송 소요시간을 명시한 곳은 **10곳 중 2곳뿐**이고, 확인된 최속이 사주대가의 **12시간**이다. 그 12시간조차 후기에 "진짜 빨리 보내주셨어요"로 인용된다.

**우리 10분은 그보다 72배 빠르다.** 그리고 8곳은 아예 안 밝힌다. 후기 0건으로도 쓸 수 있는 유일한 압도적 숫자다.

### ④ 갤러리 10칸은 **고객이 채워준다** — 다만 우리는 아직 아니다
10곳 전부 10칸을 꽉 채웠는데, **업주가 직접 올린 건 중앙값 1.5장**이다. 나머지는 고객이 후기에 첨부한 캡처가 자동 편입된 것. 10장 전부 UGC인 곳도 3곳이다.

우리는 후기 0건이라 **10칸을 전부 직접 올려야 한다.** 그리고 PDF 전 페이지에 브랜드 각인을 넣어야 한다(5곳이 그렇게 함) — 나중에 고객 캡처가 편입될 때 브랜드가 같이 실리게.

### ⑤ 후기탭에는 **답글을 달지 않는다**
5점 후기에 달린 감사 답글은 **노출 100건 중 0건**. 10곳 중 7곳이 후기탭 답글 0건이다. 답글은 딱 두 경우 — 저평점 진화, 사실 정정.

감사 인사가 필요하면 후기탭이 아니라 **소식 게시글 댓글**에서 처리한다(3곳이 이 구조). 단 초 단위로 몰아 달면 안 된다 — 명리직설 9초 간격 9연속, 청담헌 76초에 10건 동일 문구는 타임스탬프가 그대로 남아 조작으로 읽힌다.

### 3-1. 공지 (상단 알림)

**공식**: ① 오해 차단 헤드라인(부정형 단정문) → ② 근거·방법 명시 → ③ 운영 실무 고지 → ④ 원칙 선언(선택) → ⑤ CTA 마감(선택)

| 수식 | 값 |
|---|---|
| 작성률 | 10곳 중 8곳. **후기 900건 이상 상위 5곳은 5/5 전원 작성** |
| 전체 글자 수 | 중앙값 74.5자 · 범위 35~99자 · **100자 넘는 곳 0곳** |
| 첫 문장 | 9~38자 · **8곳 중 8곳이 완결된 단정 종결문** |
| 첫 문장 부정문 | 8곳 중 4곳 (최다 유형) |
| 문장 수 | 중앙값 3.5문장 · 문장당 21.5자 |
| 이모지 | 8곳 중 **1곳**(🥕). 2개 이상 쓴 곳 0곳 |
| **가격 언급** | 8곳 중 **0곳** |

대표 예시 — 명리학도 사주박사(2,721후기)의 첫 문장은 **"신점이 아닙니다."** 단 9자다.

**하면 안 되는 것**

- **"진짜 후기입니다" 류 진정성 호소** — 544·396후기 2곳뿐이고 상위 4곳은 0곳. 후기가 없을수록 만지고 싶어지지만 상위권 공식이 아니고, **우리는 후기 0건이라 쓰는 순간 거짓이 된다**

### 3-2. 소개글

**공식**: ① 신뢰 숫자 헤드라인(첫 줄 고정) → ② 방법론 선언 → ③ 공감 호명 → ④ 의미부여 → ⑤ 범위·스펙 → ⑥ 리스크 제거·희소성 → ⑦ 권유 문장(마지막 줄 고정) → ⑧ 별표 CTA 3연타

앞뒤 두 슬롯만 위치 고정, 중간은 순서 가변.

| 수식 | 값 |
|---|---|
| 글자 수 — **후기 2,500건 이상 4곳** | **180~373자에 4곳 전부 수렴**(중앙값 292자). 100자 미만 0곳 |
| 글자 수 — 후기 1,000건 미만 | 중앙값 72자. 100자 미만 5곳은 전부 후기 905건 이하 |
| **이모지** | **10곳 중 10곳이 0개.** 예외 없는 유일한 100% 규칙 |
| **빈 줄로 문단 나누기** | **10곳 중 0곳.** 전부 홑 줄바꿈만 |
| 홈에 구분선(=====, ━━━) | **홈 0곳** / 소식 본문에서는 5곳 — 장식은 소식으로 미룬다 |

> **은유는 다수 규칙이 아니다.** 이전 조사에서 "나침반 4곳"으로 알고 있었는데, 원문을 다시 뜯으니 **1곳**이다. 클리셰를 피하려고 뒤집을 필요조차 없다.

**하면 안 되는 것**

- CTA 0회 — 다수(7곳)지만, **다수를 따르면 지고 소수를 따르면 이기는 지점**

### 3-3. 소식 (게시글)

**공식 14블록**: ① 대표글 1개 몰빵 → ② 제목 23자 내 오퍼/역설 → ③ 후크: 고객의 실패 경험 → ④ 디마케팅 선언 → ⑤ 숫자 불릿 → ⑥ 방법론 공개(+AI 표기) → ⑦ 결과물 스펙 → ⑧ 목차 10항목 → ⑨ 자가진단 체크리스트 5줄 → ⑩ 가격표 → ⑪ 리스크 리버설 → ⑫ 희소성·마감 → ⑬ 오해 차단(대면❌전화❌신점❌) → ⑭ 채팅 CTA + 진입 키워드

| 업체당 글 수 | 중앙값 4개. **상위 5곳 5.8개 vs 하위 5곳 3.6개 — 개수와 성과는 무관** |
| 대표글이 만드는 문의 비중 | 중앙값 **99.1%** (9곳 중 7곳이 96%↑) |
| 조회 10만+ 글 제목 길이 | 중앙값 23자 · 범위 19~29자 · **29자 초과 0건**(30자 넘으면 잘림 확인) |
| 대표글 블록 수 | 중앙값 20개 |

**AI 자백형 3곳의 공통 문법**: ① 쓴다고 인정 → ② AI가 하는 일의 범위를 좁게 한정 → ③ 판단·검수는 사람. 우리가 쓸 수 있는 유일한 형태다.

단, **AI 해명글은 문의를 만드는 글이 아니라 방어용**이다. 대표글 대비 트래픽 기여가 사주대가 기준 0.26%. 그래도 CTA는 넣어야 한다 — 사주명리연구소 AI해명글은 364조회에 CTA가 없어 문의 0건이었다.

**하면 안 되는 것**
- **정보성 사주 지식글 양산** — 12개 표본 전환 중앙 0.83%로 판매글의 1/3. 삼성명리는 10글 중 6글이 지식글이고 총 문의 101건
- CTA 없는 글 — 실증 2건 모두 문의 0
- **후기 수 부풀리기** — 팔자(실제 7,147 → "7,300개 이상"), 별빛(실제 740 → "1,000개 이상"). **우리는 0건이라 이 슬롯을 흉내 내는 순간 즉시 허위 표시**

- 이미지 과다 — 5장 이상 4곳 전환 1.93% vs 텍스트 전용 4곳 3.16%. **후기 1·2·3위 전부 이미지 0장**

### 3-4. 후기

**고객 후기 8슬롯**: ① 트리거 고백 → ② 반신반의 고백 → ③ 숫자 충격 → ④ 적중 증거 → ⑤ 정서 전환 → ⑥ 왕복 응대 감동 → ⑦ 비교 우위 → ⑧ 행동 선언

| 수식 | 값 |
|---|---|
| 후기 평균 길이 | 중앙값 103자 · 범위 60~168자 |
| **후기 수 ↔ 길이 역상관** | 상위 3곳 84.1자 vs 하위 3곳 106.8자 — **후기 수와 후기 품질은 다른 지표** |
| 후기탭 답글률 | 100건 중 4건 (저평점 방어 3 + 사실 정정 1) |
| **5점 후기 감사 답글** | **100건 중 0건** |
| 답글 0건 업체 | 10곳 중 7곳 |
| 명시적 불만 비율 | 100건 중 12건 |
| 고객이 자발적으로 센 페이지 수 | 16~188장 (상위권 표준 100~140p) |
| AI 프레임 등장 | **10곳 중 7곳** (칭찬 축 3 / 의혹 축 4) |
| 분량 부작용 불만 | **100페이지 이상 4곳 전부에서 발생** |

**긴 후기를 만드는 세 조건** — (1) 왕복(추가질문→답변) (2) 검증 가능한 사후 결과 (3) 기대 초과가 숫자로 측정되는 순간. 셋 다 없으면 "좋아용" 한 줄로 끝난다.

**하면 안 되는 것**
- **저평점에 조목조목 반박** — 별빛사주가 27분 만에 5단 반박문을 달았고, 그 결과 1.0점 후기가 사진 6장과 함께 프로필 상단에 고정됐다. 반박은 악평의 체류시간을 늘린다
- **"감명가가 직접 한 자 한 자 썼다"** — 이 문구를 건 곳들이 정확히 거기서 찔린다: *"제미나이가 더 잘봐요"*, *"무료어플이 훨씬 나은거같아요"*, *"AI로 사주봐주신거라는데 어찌된건가요"*(사진 6장 첨부)
- **분량으로 방어하기** — 100~188페이지를 보내고도 "하나도 안맞아요"가 나온다. 페이지 수는 적중률을 방어하지 못한다
- 지킬 수 없는 약속 문구화 — 별빛사주 "사후 5일간 무제한 질문"이 미이행되자 **그 문구가 그대로 1점 후기 본문**이 됐다

### 3-5. 가격

**공식**: ① 진입단(주력의 1/3~1/2, 배지 없음) → ② 주력 1인 종합단([대표] 배지 필수) → ③ 확장단(2인, 주력×1.8배 · 단 1인가×2보다 반드시 저렴) → ④ 단품단(선택)

각 줄 = `[등급어 + 인원수] + [숫자 + "원~"] + [숫자 든 한 줄 설명]`

| 수식 | 값 |
|---|---|
| **"원~" 표기** | **32/32 항목 (100%).** 이 면의 유일한 무조건 규칙 |
| 단 수 | 중앙값 3단 · 9곳 중 6곳이 2~3단 |
| 주력 1인 종합가 | **중앙값 29,900원** (29,800·29,900이 후기 1위·2위) |
| 최상위단 | 중앙값 50,000원 |
| 주력 → 최상위 배수 | 중앙값 1.80배 |
| 최저 → 최고 스프레드 | 중앙값 2.00배 · **후기 1위는 5.56배**(9,900→55,000) |
| 2인 상품이 1인×2보다 쌈 | 9곳 중 7곳 (표준 할인폭 7~10%) |
| 대표 배지 | 전체 32항목 중 13개(40.6%) · **배지 쓰는 6곳 전부 1인 주력에 부착** |
| 900원 끝자리 | 9곳 중 3곳 — **다만 후기 1·2위가 이쪽** |
| 설명문에 숫자 근거 | 9곳 중 6곳 |
| **납기 명시** | **9곳 중 1곳**("하루~이틀") |

**우리 사다리는 후기 1위와 사실상 같다**

| | A | B | C | 배수 |
|---|---:|---:|---:|---|
| 팔자 읽어주는 사람(7,147후기) | 9,900 | 29,800 | 55,000 | 1 : 3.01 : 5.56 |
| **오롭미** | 4,900 | 14,900 | 24,900 | **1 : 3.04 : 5.08** |

절대가는 업계 중앙값의 **정확히 절반**(B 14,900 ÷ 29,900 = 0.498), 엔트리는 **1/5**. C 24,900원은 1인 2건(29,800원)보다 16.4% 싸서 "묶음은 1인×2보다 싸게" 규칙도 충족한다.

**하면 안 되는 것**
- **고액 정가 화살표 앵커**("159,000 → 45,000") — 쓰는 곳은 청담헌 1곳뿐이고 후기 396건으로 최하위. **우리는 실거래 이력이 없어 존재한 적 없는 정가를 표기하면 표시광고법상 허위 할인이다. 절대 금지**
- 7단 백화점 진열 — 1곳뿐이고 후기 하위 3위
- 전 항목 배지 도배 — 청담헌 5/5 전부 배지, 후기 최하위. **배지가 전부면 배지가 없는 것과 같다**
- 엔트리에 배지 달기 — 후기 1위는 9,900원 칸만 비워뒀다

## 6. 결정이 필요한 것 하나 — 추가질문

**10곳 중 10곳이 "추가질문 무제한"을 건다.** 후기 길이를 결정하는 최대 변수이고, 어기면 그 문구가 그대로 1점 후기 제목이 된다.

**결정: 무제한으로 간다** (2026-08-07, 사장님 판단).

근거 — 10곳 전원이 걸고 있어 없으면 그것만으로 뒤처지고, 왕복이 긴 후기를 만드는 최대 변수다. 첫 후기 10~20건까지는 당근 채팅으로 오는 질문 양이 감당 가능하다.

**단, 이건 지켜야만 성립하는 약속이다.** 별빛사주는 "사후 5일간 무제한 질문"을 못 지키자 그 문구가 그대로 1점 후기 본문이 됐다. 감당이 안 되기 시작하면 **문구를 먼저 좁히고**(신규 손님부터 적용) 이미 약속한 손님은 끝까지 지킨다. 순서를 바꾸면 그게 곧 악평이 된다.
