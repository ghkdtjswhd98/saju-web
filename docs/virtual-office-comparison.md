## 2. 최종 추천 + 차점

**최종 추천: 커먼스페이스 (연 132,000원, VAT포함)**
- 가격: 기준가(코워크시티 12개월 240,000원)의 55%, 무약정 기준(480,000원)의 27.5%. 의뢰인은 지역 무관이므로 '서울 외 지점' 최저가 조건에 정확히 부합.
- 폐업 리스크: 전 지점 자가소유 직영 → 전대차가 아닌 **정식 임대차계약**. 저가 업체의 최대 리스크(전대업체 폐업 → 주소 무효 → 사업자·PG·스토어 연쇄 변경)를 구조적으로 회피. 업력 약 5년((주)폴인라이프, 2021~).
- 서류: 전자계약 즉시 임대차계약서 다운로드(사업자등록 첨부용). 전 지점 2종 근린생활시설로 통신판매업 등록 가능.
- 우편: 도착 알림 + 무료 스캔 전송 — 코워크시티는 이게 월 5,000원 유료.
- 해지 유연성: 1개월 단위 계약이라 불만족 시 손실이 최대 1개월치(1.1만원). 장기 선납형 후보들과 결정적 차이.
- 조건: 최종 월액이 상담에서 확정되는 구조이므로, **상담 결과 월 11,000원(VAT포함)에서 유의미하게 오르면 차점과 재비교**할 것.

**차점: 코워크시티 12개월 (연 240,000원, VAT포함)**
- 요금이 완전 공개·검증된 곳 중 무보증금 기준 균형점. 임대차계약서+사용승낙서 제공, 지점 수 최다(고양 덕양구 3개 지점 — 고양 주소가 필요해지면 유일한 실질 대안).
- 감점 요인: 전대차(제휴) 구조, 우편 내용확인 유료(실비교가 월 25,000원), 무약정 상품도 첫 3개월 선납.
- 참고: 비범한사무실(연 198,000원~)이 더 싸지만 '~부터' 가격 + 초기비용·환불 규정·법인정보 비공개로 리스크 체크리스트 위반이 많아 차점에서 제외. 안전성 최우선이면 소호스페이스 24개월(첫해 264,000원, 업력 8년)이 대안.

## 3. 피해야 할 곳 / 신호

**피해야 할 곳:**
- **하이스페이스**: 절대 최저 월액(9,900원)이지만 24개월치 약 23.8만원 선납 강제 + 화성 단일 지점 + 업력 미확인 + 해지규정 비공개. 폐업 시 손실이 가장 큰 구조 — 아낀 돈보다 리스크가 큼.
- **오피스밸리·유레카오피스·히든오피스**: 공식 웹 채널 소멸/실체 미확인. 제외.
- **마인오피스·정오비즈니스센터·비즈니스114·세이브오피스**: 요금 비공개 상담 유도형 — 비교 자체가 불가.

**위험 신호 (리스크 조사 기준):**
- 요금표 비공개 또는 '월 X원부터~' 표기 (실제가는 상담에서 오름)
- 건물 소유 여부 불명(전대차) — 건물주 분쟁만으로 주소 소멸 가능
- 업력 2년 미만 + 법인정보 미공개 + 장기 총액 선납 조합
- '우편물 수령 전용' 초저가 계약서(공용공간·명패 없음) — 세무서 반려 확률 높음
- 환불·중도해지 규정 비공개, 우편 알림 체계 없음, 한 주소 등록 사업자 과다
- 과밀억제권역 외 주소로 세액감면 노리는 '주소세탁' 권유 — 국세청 빅데이터 단속으로 직권폐지+추징 사례 있음

## 4. 계약 시 확인 체크리스트 (커먼스페이스 카톡 상담 기준)

1. **확정 금액**: 계약 지점(파주/김포 등) 기준 확정 월액·VAT 포함 여부, "임대료 외 추가비용 0" 및 **갱신 시 인상 여부** 서면 확인
2. **계약서 형태**: 임대차계약서(전대차 아님) 샘플 수령 + 해당 지점 등기부등본으로 자가소유 확인, 사업자등록 첨부 가능 명시 확인
3. **해지·환불**: 1개월 단위 갱신 방식과 중도해지 환불 규정 서면 확인
4. **우편물**: 도착 알림+무료 스캔 범위, 등기·세무서 우편 처리 방식 확인 — 계약과 별개로 **홈택스 전자송달 신청**으로 이중 방어
5. **업종·주소 상태**: 통신판매업(무형 디지털 서비스, 무재고) 등록 가능 지점인지 + 해당 주소 등록 사업자 수 과다 여부 확인 — 사업자등록 신청 시 '무재고 위탁/디지털 서비스'임을 명기
